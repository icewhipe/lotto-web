## 🐛 ЕСЛИ НЕ РАБОТАЕТ

### ❌ Ошибка: "EADDRINUSE: port 5000 already in use"

```bash
# Убей все процессы на портах
lsof -ti:5000 | xargs kill -9
lsof -ti:3000 | xargs kill -9
lsof -ti:5173 | xargs kill -9

# Или используй скрипт:
npm run kill:ports

# Теперь запускай:
npm start
```

---

### ❌ Ошибка: "Redis connection refused"

**Это нормально!** Backend работает без Redis.

Если хочешь включить Redis (уже установлен):
```bash
brew services start redis
redis-cli ping  # Должно вернуть PONG
```

---

### ❌ Ошибка: "PostgreSQL not running"

```bash
# Запусти PostgreSQL
brew services start postgresql@14

# Проверь
psql -U vasiliidyahenko -d lptt_db -c "SELECT 1"
```

---

### ❌ Ошибка: "Cannot find module"

```bash
# Переустанови зависимости
npm run install:all

# Или вручную:
npm install
cd backend && npm install
```
