## 3️⃣ НАСТРОЙКА БАЗЫ ДАННЫХ

### Запусти PostgreSQL:

```bash
brew services start postgresql@14
```

### Создай базу данных:

```bash
createdb lptt_db
```

### Настрой .env файл:

```bash
cd backend
cat > .env << 'EOF'
DATABASE_URL="postgresql://vasiliidyahenko@localhost:5432/lptt_db"
JWT_SECRET="lptt-secret-key-2024-super-secure"
JWT_EXPIRES_IN="7d"
PORT=3000
NODE_ENV=development
CORS_ORIGIN="http://localhost:5173"
EOF
```

### Примени схему БД:

```bash
npx prisma db push
```

**Ожидаемый вывод:**
```
✅ Your database is now in sync with your Prisma schema.
```

### Сгенерируй Prisma Client:

```bash
npx prisma generate
```

## ⚠️ ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Backend не запускается:

```bash
cd backend
rm -rf node_modules package-lock.json
npm install
npx prisma generate
npm run dev
```

### Frontend не запускается:

```bash
rm -rf node_modules
npm install
npm run dev
```

### База данных пустая:

```bash
cd backend
npm run seed:full
```

### Полная переустановка:

```bash
# Удалить всё
rm -rf node_modules backend/node_modules
rm package-lock.json backend/package-lock.json

# Удалить базу
dropdb lptt_db

# Создать заново
createdb lptt_db

# Установить зависимости
npm install
cd backend && npm install

# Применить схему
npx prisma db push

# Заполнить данными
npm run seed:full

# Запустить
npm run dev (backend)
npm run dev (frontend из корня)
```
