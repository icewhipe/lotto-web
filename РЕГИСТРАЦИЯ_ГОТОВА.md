## ✅ ЧТО СДЕЛАНО:

### **УМНАЯ ЛОГИКА С ИНВАЙТ-КОДАМИ**

**Роли:**
- 🎓 **Абитуриент** - регистрация БЕЗ кода (свободная)
- 👨‍🎓 **Студент** - нужен инвайт-код от администрации
- 👨‍👩‍👦 **Родитель** - нужен инвайт-код от администрации  
- 👨‍🏫 **Преподаватель** - нужен инвайт-код от администрации

**Почему так:**
- Абитуриенты могут регистрироваться сами (подача заявки)
- Остальные роли требуют подтверждения от администрации
- Это предотвращает несанкционированный доступ

## 🚀 КАК ПРОТЕСТИРОВАТЬ:

```bash
# 1. Очисти кэш
Cmd+Shift+Delete

# 2. Запусти
npm run dev

# 3. Открой
http://localhost:5173
```

### **ТЕСТ 1: Абитуриент (БЕЗ кода)**
1. Нажми "Войти" на заглушке
2. Нажми "Зарегистрироваться"
3. Выбери 🎓 **Абитуриент**
4. Заполни форму:
   ```
   ФИО: Петров Пётр Петрович
   Email: petrov@example.com
   Телефон: +7 999 123 45 67
   Пароль: 123456
   Подтверждение: 123456
   ```
5. Нажми "Зарегистрироваться"
6. **Готово! ✅**

### **ТЕСТ 2: Студент (С кодом)**
1. Выбери 👨‍🎓 **Студент**
2. Увидишь запрос кода
3. Введи код: `ABCD1234` (или любой >= 6 символов)
4. Нажми "Продолжить"
5. Заполни форму
6. **Готово! ✅**

### **ТЕСТ 3: Родитель/Преподаватель**
Аналогично студенту - нужен код!

---

## 💬 ГДЕ ВЗЯТЬ КОД:

### **Для тестирования:**
Любой код >= 6 символов работает (симуляция)

### **В реальности (после backend интеграции):**
1. Админ создаёт инвайт-код в панели
2. Код привязывается к роли и группе
3. Код выдаётся студенту/родителю/преподавателю
4. Они регистрируются с этим кодом
5. Аккаунт создаётся с правильной ролью

### **Типы кодов:**

```
Код: STUD-2024-1A
Роль: Студент
Группа: ИС-11
Срок действия: До 01.09.2024
```

**Родитель:**
```
Код: PARENT-001
Роль: Родитель
Привязка: К студенту Иванов И.И.
Срок действия: Бессрочно
```

**Преподаватель:**
```
Код: TEACH-2024
Роль: Преподаватель
Доступ: Полный
Срок действия: Бессрочно
```

### **Админ может:**
- Создавать неограниченное количество кодов
- Привязывать к ролям и группам
- Устанавливать срок действия
- Деактивировать использованные коды
- Смотреть кто использовал код
