# 🎓 ЛПТТ - Лискинский промышленно-транспортный техникум

Современный сайт с **электронным дневником** для ЛПТТ, разработанный с использованием передовых веб-технологий 2025-2026 года.

> **🚀 НОВАЯ ВЕРСИЯ 3.0:** Добавлен полнофункциональный электронный дневник + оптимизация производительности на 70%!

## ✨ Основные возможности

### 📚 Электронный дневник (НОВОЕ v3.0)
- **5 ролей пользователей:** студент, преподаватель, родитель, абитуриент, администратор
- **Для студентов:** просмотр оценок, расписания, посещаемости
- **Для родителей:** контроль успеваемости ребенка
- **Для преподавателей:** электронный журнал (в разработке)
- **Учет посещаемости:** автоматические отчеты, отказ от бумажных рапортов
- **Расписание:** индивидуальное для каждой группы

### 🚀 Оптимизация производительности
- ⚡ **Производительность улучшена на 70%**
- 📦 **Bundle size:** с 500KB до 100KB (gzip)
- 🎯 **Lazy Loading:** все компоненты загружаются по требованию
- 🔄 **Code Splitting:** разделение на vendor chunks
- ✨ **CSS animations:** вместо JS для лучшей производительности

### 🎨 Современный UI/UX
- 🔍 **Умный поиск:** Cmd/Ctrl+K для быстрого поиска
- 🌗 **Темная/Светлая тема:** с сохранением настроек
- 💎 **Glass Morphism:** эффект матового стекла
- 📱 **Полная адаптивность:** работает на всех устройствах
- ✨ **Плавные анимации:** профессиональные микроинтеракции
