### Установка

```bash
# 1️⃣ Клонировать репозиторий
git clone https://github.com/icewhipe/lotto-web.git
cd lotto-web

# 2️⃣ Установить зависимости Frontend
npm install

# 3️⃣ Установить зависимости Backend
cd backend
npm install
cd ..

# 4️⃣ Настроить базу данных
cd backend
cp .env.example .env
# Отредактируйте .env с вашими данными PostgreSQL

# 5️⃣ Применить миграции
npx prisma migrate dev
npx prisma generate
cd ..

# 6️⃣ Запустить проект
npm run dev:all
```

## 🎮 Команды

### Development

```bash
# Запустить frontend (http://localhost:5173)
npm run dev

# Запустить backend (http://localhost:3000)
cd backend && npm run dev

# 🚀 Запустить ВСЁ СРАЗУ (рекомендуется!)
npm run dev:all
```

### Build

```bash
# Build frontend для production
npm run build

# Build backend
cd backend && npm run build

# Preview production build
npm run preview  # http://localhost:4173
```

### Database

```bash
cd backend

# Применить миграции
npx prisma migrate dev

# Сгенерировать Prisma Client
npx prisma generate

# Открыть Prisma Studio (GUI для БД)
npx prisma studio  # http://localhost:5555

# Заполнить БД тестовыми данными
npx prisma db seed
```

### Quality Assurance

```bash
# Проверка кода (ESLint)
npm run lint

# Автоисправление lint ошибок
npm run lint:fix

# Форматирование кода (Prettier)
npm run format

# Проверка типов TypeScript
npm run type-check
```

### Создание компонента

```typescript
// src/components/MyComponent.tsx
import { motion } from 'framer-motion'

interface MyComponentProps {
  title: string
  isDark?: boolean
}

export default function MyComponent({ title, isDark = false }: MyComponentProps) {
  return (
    <motion.div
      initial={{ opacity: 0, y: 20 }}
      animate={{ opacity: 1, y: 0 }}
      className={`p-6 rounded-2xl ${
        isDark ? 'bg-slate-800 text-white' : 'bg-white text-slate-900'
      }`}
    >
      <h2 className="text-2xl font-bold">{title}</h2>
    </motion.div>
  )
}
```

### Добавление API endpoint

```typescript
// backend/src/routes/myRoute.ts
import { Router } from 'express'
import { authenticateJWT, requireRole } from '../middleware/auth'

const router = Router()

router.get('/my-endpoint', authenticateJWT, requireRole(['teacher']), async (req, res) => {
  try {
    // Ваша логика
    res.json({ success: true, data: [] })
  } catch (error) {
    res.status(500).json({ error: 'Server error' })
  }
})

export default router
```

## 🐛 Troubleshooting

<details>
<summary><b>Build fails</b></summary>

```bash
# Очистить кэш и пересобрать
rm -rf node_modules dist backend/node_modules backend/dist
npm install
cd backend && npm install && cd ..
npm run build
```

</details>

<details>
<summary><b>Database connection error</b></summary>

```bash
# 1. Проверьте что PostgreSQL запущен
sudo systemctl status postgresql

# 2. Проверьте .env файл
cat backend/.env

# 3. Проверьте подключение
psql -U your_user -d lptt
```

</details>

<details>
<summary><b>Port already in use</b></summary>

```bash
# Frontend (5173)
lsof -ti:5173 | xargs kill -9

# Backend (3000)
lsof -ti:3000 | xargs kill -9

# Или измените порт в конфигурации
```

</details>

**Больше решений:** [docs/MIGRATION_GUIDE.md#troubleshooting](docs/MIGRATION_GUIDE.md#-troubleshooting)
