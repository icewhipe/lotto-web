# 🎓 ЛПТТ - Лискинский промышленно-транспортный техникум

Современный, подробный сайт для ЛПТТ, разработанный с использованием передовых веб-технологий 2025-2026 года.

> **✅ ОБНОВЛЕНО:** Сайт стал в **2 раза подробнее**! Добавлено 7 новых секций с детальной информацией о техникуме.

## ✨ Технологический стек

### Фронтенд
- **React 18** - современная библиотека для создания UI
- **TypeScript** - строгая типизация для надежного кода
- **Vite** - сверхбыстрый сборщик нового поколения
- **Tailwind CSS 3** - utility-first CSS фреймворк
- **Framer Motion** - продвинутая библиотека для анимаций

### Инструменты разработки
- **ESLint** - линтер для TypeScript/React
- **PostCSS** - трансформация CSS
- **SWC** - супербыстрый компилятор для React

## 🎨 Дизайн-тренды 2025-2026

- ✅ **Гласморфизм** (Glassmorphism) - эффект матового стекла
- ✅ **Градиенты и яркие цвета** - современная цветовая палитра
- ✅ **Плавные анимации** - микроинтеракции с Framer Motion
- ✅ **Темная/Светлая тема** - адаптивная смена режимов
- ✅ **3D эффекты** - hover эффекты с перспективой
- ✅ **Адаптивный дизайн** - mobile-first подход
- ✅ **Компонентный подход** - переиспользуемые React компоненты
- ✅ **Оптимизация производительности** - code splitting, lazy loading

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск dev-сервера

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Сборка для продакшена

```bash
npm run build
```

### Предпросмотр production-сборки

```bash
npm run preview
```
