## 🎯 ЧТО ТЕПЕРЬ ДЕЛАТЬ:

### **СЕЙЧАС:**

1. **Запусти Backend:**
   ```bash
   cd /workspace/backend
   npm run dev
   ```

2. **Запусти Frontend:**
   ```bash
   cd /workspace
   npm run dev
   ```

3. **Открой браузер:**
   ```
   http://localhost:5173
   ```

4. **Войди студентом:**
   ```
   Email: student@lptt.ru
   Пароль: (из seed)
   ```

5. **Проверь вкладки:**
   - Главная ✅
   - Оценки ✅
   - Посещаемость ✅
   - Расписание ✅
