## 📅 Управление расписанием

### Просмотр расписания:

**По группам:**
```
┌──────────────────────────────────────┐
│  РАСПИСАНИЕ ИС-21 (Понедельник)      │
├──────────────────────────────────────┤
│  1. 09:00-10:30  Математика          │
│     Иванова М.П.  Каб. 205           │
│                                      │
│  2. 10:45-12:15  Информатика         │
│     Петров А.С.   Каб. 301           │
│                                      │
│  3. 12:30-14:00  История             │
│     Смирнова Е.В. Каб. 102           │
└──────────────────────────────────────┘
```

**По преподавателям:**
- 👨‍🏫 Нагрузка преподавателя
- 📅 Свободные окна
- 🏫 Кабинеты

**По кабинетам:**
- 🏫 Загруженность кабинетов
- 📅 Свободные аудитории
- ⚠️ Конфликты расписания

### Создание расписания:

1. **Выбери группу**
2. **Выбери день недели**
3. **Добавь пару:**

```
⏰ Время:        [09:00 - 10:30]
📚 Предмет:      [Выбрать из списка]
👨‍🏫 Преподаватель: [Выбрать]
🏫 Кабинет:      [205]
📌 Тип:          [Лекция/Практика/Лаб]
```

### Замены преподавателей:

**При отсутствии преподавателя:**

1. Найди пару в расписании
2. Нажми "Замена"
3. Выбери заменяющего преподавателя
4. Система уведомит:
   - 👨‍🏫 Заменяющего преподавателя
   - 👨‍🎓 Группу студентов
   - 📧 Администрацию

```
⚠️ ЗАМЕНА:

Дата: 15.10.2024
Пара: 2 (10:45-12:15)
Группа: ИС-21
Предмет: Математика

Отсутствует: Иванова М.П.
Заменяет:    Петров А.С.
```

## 🎯 Управленческие решения

### Принятие мер:

**При низкой успеваемости:**
- 📚 Организация дополнительных занятий

- ⚠️ Предупреждение об отчислении

- 📞 Звонок родителям
- 📧 Письмо родителям

- ⚠️ Административные меры

- 💬 Личная беседа
- 📝 Письменное предупреждение
