# 👨‍💼 Руководство для администратора

Руководство по управлению системой ЛПТТ Электронный Техникум.

---

## 🔑 Вход в систему

1. Открой административную панель
2. Введи административные учётные данные
3. Email: `admin@lptt.ru`
4. Пароль: (предоставлен IT-отделом)

---

## 🎛️ Административная панель

После входа ты увидишь панель управления с разделами:

- 👥 **Пользователи** - управление пользователями
- 👨‍🎓 **Группы** - управление группами
- 📚 **Предметы** - управление предметами
- 🎫 **Инвайт-коды** - генерация кодов приглашения
- 📊 **Статистика** - общая статистика системы
- ⚙️ **Настройки** - настройки системы

---

## 👥 Управление пользователями

### Просмотр пользователей:

**Фильтры:**
- 🔍 **Поиск** - по имени или email
- 🎭 **Роль** - Студент, Преподаватель, Родитель, Админ
- ✅ **Статус** - Активный, Неактивный

**Информация о пользователе:**
- 👤 ФИО
- 📧 Email
- 🎭 Роль
- 📅 Дата регистрации
- ✅ Статус

### Создание пользователя:

1. Нажми **"Создать пользователя"**
2. Заполни форму:

```
👤 ФИО:          [Полное имя]
📧 Email:        [Уникальный email]
🔒 Пароль:       [Минимум 6 символов]
🎭 Роль:         [Выбрать роль]
👥 Группа:       [Только для студентов]
📚 Специальность: [Только для преподавателей]
```

### Роли пользователей:

- 👨‍🎓 **STUDENT** - студент
  - Требуется группа
  - Автоматически создаётся студенческий номер

- 👨‍🏫 **TEACHER** - преподаватель
  - Требуется должность
  - Требуется кафедра

- 👨‍👩‍👧 **PARENT** - родитель
  - Можно привязать детей
  - Требуется контактная информация

- 🎓 **APPLICANT** - абитуриент
  - Для регистрации до зачисления

- 👨‍💼 **ADMIN** - администратор
  - Полный доступ к системе

### Редактирование пользователя:

1. Найди пользователя в списке
2. Нажми кнопку **"Редактировать"**
3. Измени нужные поля
4. Сохрани изменения

### Удаление пользователя:

⚠️ **ВНИМАНИЕ**: Удаление пользователя удалит все связанные данные!

1. Найди пользователя
2. Нажми **"Удалить"**
3. Подтверди действие

### Активация/Деактивация:

- ✅ **Активировать** - пользователь может войти
- ❌ **Деактивировать** - блокировка доступа (без удаления данных)

## 👨‍🎓 Управление группами

### Просмотр групп:

**Информация о группе:**
- 📛 **Название** - например, ИС-21
- 📅 **Год поступления** - 2021
- 📚 **Специальность** - направление
- 👥 **Количество студентов**
- 📊 **Средний балл группы**
- ✅ **Процент посещаемости**

### Создание группы:

1. Нажми **"Создать группу"**
2. Заполни форму:

```
📛 Название:      [Например, ИС-21]
📅 Год поступления: [2024]
📚 Специальность:   [Выбрать из списка]
```

### Редактирование группы:

1. Найди группу в списке
2. Нажми **"Редактировать"**
3. Измени данные
4. Сохрани

### Управление студентами группы:

- 👥 **Просмотр студентов** - список всех студентов
- ➕ **Добавить студента** - зачислить в группу
- ➖ **Удалить студента** - отчислить из группы
- 🔄 **Перевести студента** - в другую группу

---

## 📚 Управление предметами

### Просмотр предметов:

**Информация о предмете:**
- 📚 **Название** - название предмета
- 🔢 **Код** - уникальный код
- 📖 **Специальность** - для какой специальности
- 👨‍🏫 **Преподаватель** - кто ведёт
- 👥 **Количество групп** - сколько групп изучает

### Создание предмета:

1. Нажми **"Создать предмет"**
2. Заполни форму:

```
📚 Название:      [Математика]
🔢 Код:           [MATH-101]
📖 Специальность: [Выбрать]
👨‍🏫 Преподаватель: [Выбрать из списка]
```

### Назначение преподавателя:

1. Найди предмет
2. Нажми **"Назначить преподавателя"**
3. Выбери преподавателя из списка
4. Сохрани

## 🎫 Инвайт-коды

Система приглашений для регистрации.

### Просмотр кодов:

**Информация:**
- 🎫 **Код** - уникальный код
- 👥 **Группа** - для какой группы
- 👤 **Использован** - кем и когда
- ⏰ **Срок действия** - до какой даты
- ✅ **Статус** - активный/использован/истёк

### Генерация кодов:

1. Нажми **"Сгенерировать коды"**
2. Заполни параметры:

```
👥 Группа:           [Выбрать группу]
🔢 Количество:       [Сколько кодов]
⏰ Срок действия:    [Дней]
```

3. Система создаст коды
4. Скопируй коды для передачи студентам

### Формат кода:

```
LPTT-ИС21-AB12CD34
```

### Отправка кодов:

**Способы:**
- 📧 **Email** - автоматическая рассылка
- 📋 **Список** - скопировать и отправить вручную
- 📄 **Excel** - экспорт в файл

## 🔄 Резервное копирование

### Создание бэкапа:

1. Перейди в **"Настройки" → "Резервное копирование"**
2. Нажми **"Создать бэкап"**
3. Система создаст копию БД
4. Скачай файл бэкапа

### Восстановление:

1. Перейди в **"Настройки" → "Восстановление"**
2. Выбери файл бэкапа
3. Подтверди восстановление
4. ⚠️ Текущие данные будут перезаписаны!

### Автоматические бэкапы:

```
⏰ Расписание: [Ежедневно, 03:00]
📁 Хранить: [30 дней]
☁️ Облачное хранилище: [Опционально]
```
