# 👨‍💼 Полное руководство администратора - Создание специальностей, групп, расписания

## 📚 ЧАСТЬ 1: Управление специальностями

### Создание специальности

1. **Войди в админ панель**
   ```
   Email: admin@lptt.ru
   Пароль: 123456
   ```

2. **Перейди в "Специальности"**

3. **Нажми "Создать специальность"**

4. **Заполни форму:**
   ```
   ┌────────────────────────────────────────┐
   │  СОЗДАНИЕ СПЕЦИАЛЬНОСТИ                │
   ├────────────────────────────────────────┤
   │  Название:                             │
   │  Информационные системы и              │
   │  программирование                      │
   │                                        │
   │  Код:           ИС                     │
   │                                        │
   │  Описание:                             │
   │  Разработка программного обеспечения   │
   │  и информационных систем               │
   │                                        │
   │  Срок обучения: 3 года 10 месяцев      │
   │                                        │
   │  Квалификация:  Техник-программист     │
   │                                        │
   │  [Создать]                             │
   └────────────────────────────────────────┘
   ```

### Список специальностей

После создания увидишь:

```

│  СПЕЦИАЛЬНОСТИ                                 │
```

## 👥 ЧАСТЬ 2: Управление группами

### Создание группы

1. **Перейди в "Группы"** → **"Создать группу"**

2. **Заполни форму:**
   ```
   ┌────────────────────────────────────────┐
   │  СОЗДАНИЕ ГРУППЫ                       │
   ├────────────────────────────────────────┤
   │  Название:      ИС-21                  │
   │                                        │
   │  Специальность: [Выбрать]              │
   │  ▼ Информационные системы и            │
   │    программирование                    │
   │                                        │
   │  Год поступления: 2021                 │
   │                                        │
   │  Куратор:       [Выбрать преподавателя]│
   │  ▼ Иванова Мария Петровна              │
   │                                        │
   │  Староста:      [Выбрать студента]     │
   │  (после добавления студентов)          │
   │                                        │
   │  [Создать]                             │
   └────────────────────────────────────────┘
   ```

### Добавление студентов в группу

**Способ 1: При создании студента**

При создании студента сразу выбирается группа:
```
Роль: Студент
Группа: ИС-21
```

**Способ 2: Массовый импорт**

1. Подготовь файл `students.csv`:
   ```csv
   email,name,group,student_number
   ivanov1@lptt.ru,Иванов Иван Иванович,ИС-21,ИС-21-01
   petrov2@lptt.ru,Петров Пётр Петрович,ИС-21,ИС-21-02
   ```

2. Перейди в **"Импорт"** → **"Студенты"**
3. Загрузи файл
4. Проверь предпросмотр
5. Импортируй

**Способ 3: Перевод студента**

Переместить студента из одной группы в другую:

1. Найди студента
2. Нажми **"Перевести в группу"**
3. Выбери новую группу
4. Укажи причину (опционально)
5. Подтверди

## 📅 ЧАСТЬ 3: Управление расписанием

### Создание расписания для группы

#### Шаг 1: Подготовка

Убедись что созданы:
- ✅ Специальность
- ✅ Группа
- ✅ Предметы
- ✅ Преподаватели назначены на предметы

#### Шаг 2: Создание расписания

1. **Перейди в "Расписание"**

2. **Выбери группу:** `ИС-21`

3. **Выбери день:** `Понедельник`

4. **Нажми "Добавить пару"**

5. **Заполни форму:**
   ```
   ┌────────────────────────────────────────┐
   │  ДОБАВЛЕНИЕ ПАРЫ                       │
   ├────────────────────────────────────────┤
   │  Группа:         ИС-21                 │
   │  День:           Понедельник           │
   │                                        │
   │  Пара:           [Выбрать]             │
   │  ▼ 1 пара (09:00 - 10:30)              │
   │                                        │
   │  Предмет:        [Выбрать]             │
   │  ▼ Математика                          │
   │                                        │
   │  Преподаватель:  [Автоматически]       │
   │  → Иванова М.П.                        │
   │                                        │
   │  Кабинет:        205                   │
   │                                        │
   │  Тип:            [Выбрать]             │
   │  ▼ Лекция                              │
   │     Практика                           │
   │     Лабораторная                       │
   │                                        │
   │  [Добавить]                            │
   └────────────────────────────────────────┘
   ```

6. **Повтори для всех пар и дней**

### Автоматическая генерация расписания

Для ускорения процесса:

1. **Перейди в "Расписание" → "Автогенерация"**

2. **Настрой параметры:**
   ```
   ┌────────────────────────────────────────┐
   │  АВТОГЕНЕРАЦИЯ РАСПИСАНИЯ              │
   ├────────────────────────────────────────┤
   │  Группа:          ИС-21                │
   │                                        │
   │  Пар в день:      [Выбрать]            │
   │  ▼ 3-4 пары                            │
   │                                        │
   │  Дни недели:                           │
   │  ☑ Понедельник                         │
   │  ☑ Вторник                             │
   │  ☑ Среда                               │
   │  ☑ Четверг                             │
   │  ☑ Пятница                             │
   │  ☑ Суббота                             │
   │                                        │
   │  Предметы:        [Из учебного плана]  │
   │  ☑ Математика (4 ч/нед)                │
   │  ☑ Информатика (4 ч/нед)               │
   │  ☑ Программирование (6 ч/нед)          │
   │  ...                                   │
   │                                        │
   │  [Сгенерировать]                       │
   └────────────────────────────────────────┘
   ```

3. **Система создаст расписание автоматически:**
   - Распределит предметы по дням
   - Учтёт нагрузку преподавателей
   - Исключит конфликты
   - Сбалансирует по дням

4. **Проверь и отредактируй при необходимости**

### Копирование расписания

Скопировать расписание из одной группы в другую:

1. **Перейди в "Расписание"**
2. **Нажми "Копировать расписание"**
3. **Выбери:**
   ```
   Из группы: ИС-21
   В группу:  ИС-22
   ```
4. **Система скопирует структуру**
5. **Измени преподавателей и кабинеты**
