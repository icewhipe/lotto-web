## 🎯 Общий план внедрения

### Цель проекта:
Создать единую цифровую экосистему для Липецкого Политехнического Техникума, которая:
- Автоматизирует учебный процесс
- Упрощает контроль посещаемости (RFID)
- Обеспечивает доступ к оценкам и расписанию 24/7
- Улучшает коммуникацию между студентами, преподавателями и администрацией

### Участники проекта:
1. **Администрация техникума** - принятие решений, бюджет
2. **IT отдел** - техническая поддержка, сервера
3. **Учебная часть** - предоставление данных, тестирование
4. **Преподаватели** - использование системы, обратная связь
5. **Студенты** - основные пользователи
6. **Разработчики** - внедрение, обновления

### Этап 2: Импорт данных (1 неделя)
**Цель:** Загрузить всех студентов и преподавателей в систему

#### 2.1 Создать скрипт импорта:
```typescript
// backend/src/utils/importFromExcel.ts

import * as XLSX from 'xlsx';
import prisma from '../config/database';
import bcrypt from 'bcryptjs';

async function importStudents(filePath: string) {
  // Читаем Excel
  const workbook = XLSX.readFile(filePath);
  const sheet = workbook.Sheets[workbook.SheetNames[0]];
  const data = XLSX.utils.sheet_to_json(sheet);

  for (const row of data) {
    // Генерируем временный пароль
    const tempPassword = generateTempPassword(); // Например: LPTT2024-001
    const hashedPassword = await bcrypt.hash(tempPassword, 10);

    // Создаём пользователя
    const user = await prisma.user.create({
      data: {
        email: row.email || generateEmail(row.name), // ivan.ivanov@lptt.ru
        password: hashedPassword,
        name: row.name,
        role: 'STUDENT',
        isActive: false, // Неактивен до первого входа
      }
    });

    // Создаём профиль студента
    await prisma.student.create({
      data: {
        userId: user.id,
        groupId: row.groupId,
        studentNumber: row.studentNumber,
        enrollmentDate: new Date(row.enrollmentDate),
      }
    });

    // Отправляем email с временным паролем
    await sendWelcomeEmail(user.email, tempPassword);
  }
}
```

#### 2.2 Процесс импорта:
1. Запустить скрипт импорта
2. Система создаст аккаунты с временными паролями
3. Отправит email каждому студенту/преподавателю
4. Пользователи получат:
   - Email: их email или автогенерированный
   - Пароль: временный (например, LPTT2024-001)
   - Ссылка: http://diary.lptt.ru

### Этап 3: Система регистрации (2 недели)
**Цель:** Позволить новым студентам регистрироваться самостоятельно

#### 3.1 Два типа регистрации:

##### A) Регистрация через код приглашения (рекомендуется)
**Процесс:**
1. Администрация генерирует коды приглашения для новых студентов
2. Код содержит информацию о группе и специальности
3. Студент вводит код при регистрации
4. Система автоматически определяет группу

**Пример:**
```
Код: LPTT-IS21-2024-001
      ↓    ↓    ↓    ↓
    Орг Группа Год Номер
```

##### B) Регистрация с проверкой администратором
**Процесс:**
1. Студент заполняет форму регистрации
2. Выбирает специальность и курс
3. Заявка отправляется администратору
4. Администратор проверяет и утверждает
5. Студент получает доступ

#### 3.2 Backend логика регистрации:

**Эндпоинты:**
```typescript
// 1. Проверка кода приглашения
POST /api/auth/check-invite-code
Body: { code: "LPTT-IS21-2024-001" }
Response: {
  success: true,
  data: {
    groupId: "xxx",
    groupName: "ИС-21",
    specialtyName: "Информационные системы"
  }
}

// 2. Регистрация с кодом
POST /api/auth/register-with-invite
Body: {
  code: "LPTT-IS21-2024-001",
  name: "Иван Иванов",
  email: "ivan@example.com",
  password: "secure_password",
  phone: "+7 900 123 45 67",
  birthDate: "2006-05-15"
}

// 3. Регистрация с проверкой
POST /api/auth/register-pending
Body: {
  name: "Иван Иванов",
  email: "ivan@example.com",
  password: "secure_password",
  specialtyId: "xxx",
  course: 2,
  phone: "+7 900 123 45 67",
  birthDate: "2006-05-15",
  documents: ["паспорт", "аттестат"]
}
Response: {
  success: true,
  message: "Заявка отправлена на проверку"
}

// 4. Утверждение заявки (admin)
POST /api/admin/approve-registration/:userId
Body: { groupId: "xxx" }
```

#### 3.3 Prisma модель для приглашений:

```prisma
model InviteCode {
  id          String   @id @default(uuid())
  code        String   @unique
  groupId     String
  group       Group    @relation(fields: [groupId], references: [id])
  
  usedBy      String?
  usedAt      DateTime?
  
  expiresAt   DateTime
  createdBy   String
  createdAt   DateTime @default(now())
  
  isActive    Boolean  @default(true)
  maxUses     Int      @default(1)
  currentUses Int      @default(0)
  
  @@map("invite_codes")
}

model RegistrationRequest {
  id          String   @id @default(uuid())
  name        String
  email       String
  phone       String
  birthDate   DateTime
  
  specialtyId String
  specialty   Specialty @relation(fields: [specialtyId], references: [id])
  course      Int
  
  status      RegistrationStatus @default(PENDING) // PENDING, APPROVED, REJECTED
  
  reviewedBy  String?
  reviewedAt  DateTime?
  rejectReason String?
  
  assignedGroupId String?
  
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  
  @@map("registration_requests")
}

enum RegistrationStatus {
  PENDING
  APPROVED
  REJECTED
}
```

## 🔒 Безопасность

### 1. Персональные данные

#### Согласие на обработку:
- При первом входе пользователь принимает соглашение
- Чекбокс "Согласен на обработку персональных данных"
- Возможность отозвать согласие

#### Шифрование:
- Пароли - bcrypt (salt rounds: 10)
- JWT токены - HS256
- HTTPS обязательно (SSL/TLS)
- Sensitive данные в БД - encryption at rest

### 2. Роли и права доступа

| Роль | Права |
|------|-------|
| **Студент** | Видит свои оценки, расписание, посещаемость |
| **Преподаватель** | Видит свои группы, выставляет оценки, отмечает посещаемость |
| **Родитель** | Видит данные своего ребёнка |
| **Директор** | Полная статистика, отчёты, но не редактирование |
| **Завуч** | Управление расписанием, оценками, группами |
| **Администратор** | Полный доступ ко всему |
