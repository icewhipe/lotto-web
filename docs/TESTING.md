## 🎯 Как тестировать

### 1. Запусти проект
```bash
cd /Users/vasiliidyahenko/Documents/GitHub/lotto-web
npm start
```

### 2. Открой в браузере
```
http://localhost:5173
```

### 3. Используй тестовые аккаунты

**Студент:**
- Email: `student@lptt.ru`
- Password: `123456`

**Преподаватель:**
- Email: `teacher@lptt.ru`
- Password: `123456`

**Админ:**
- Email: `admin@lptt.ru`
- Password: `admin123`

### 4. Проверь все пункты чек-листа

### 5. Открой DevTools
```
F12 или Cmd+Option+I
```

### 6. Проверь производительность
- **Performance** → запиши профиль
- **Network** → проверь загрузку
- **Console** → нет ошибок
