# 🚀 Быстрый старт — Web приложение

Запустите веб-приложение за 5 минут!

---

## ⚡ Минимальная установка

### 1. Установите Node.js

**Требуется:** Node.js 20.x или выше

```bash
# Проверьте версию
node --version  # должно быть v20.x.x или выше
npm --version   # должно быть 10.x.x или выше
```

[Скачать Node.js →](https://nodejs.org/)

---

### 2. Клонируйте репозиторий

```bash
git clone https://github.com/icewhipe/lotto-web.git
cd lotto-web
```

---

### 3. Установите зависимости

```bash
npm install
```

**Время установки:** ~2-3 минуты

---

### 4. Запустите dev server

```bash
npm run dev
```

**Откроется автоматически:** http://localhost:5173


## 🐛 Проблемы?

### Dev server не запускается

```bash
# Очистить кэш
rm -rf node_modules
npm install
```

### Port 5173 занят

```bash
# Использовать другой порт
npm run dev -- --port 3000
```

### Ошибки TypeScript

```bash
# Проверить типы
npm run type-check
```
