## 2️⃣ ЗАПУСК БАЗЫ ДАННЫХ

### **Вариант A: Homebrew (MacOS)**

```bash
# Установка (если нет)
brew install postgresql@14

# Запуск
brew services start postgresql@14

# Проверка
psql postgres -c "SELECT version();"
```

### **Вариант B: Postgres.app (MacOS)**

1. Скачай: https://postgresapp.com/
2. Запусти приложение
3. Нажми "Initialize"

### **Вариант C: Docker**

```bash
docker run --name lptt-postgres \
  -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=lptt_db \
  -e POSTGRES_USER=postgres \
  -p 5432:5432 \
  -d postgres:14

# Проверка
docker ps | grep lptt-postgres
```

### **Создай базу данных:**

```bash
# Подключись к Postgres
psql postgres

# Создай базу
CREATE DATABASE lptt_db;

# Создай пользователя (если нужно)
CREATE USER vasiliidyahenko WITH PASSWORD 'postgres';
GRANT ALL PRIVILEGES ON DATABASE lptt_db TO vasiliidyahenko;

# Выйди
\q
```

## 3️⃣ НАСТРОЙКА BACKEND

### **Перейди в папку backend:**

```bash
cd /workspace/backend
```

### **Создай .env файл:**

```bash
cat > .env << 'EOF'
# Database
DATABASE_URL="postgresql://vasiliidyahenko:postgres@localhost:5432/lptt_db"

# JWT
JWT_SECRET="your-super-secret-jwt-key-change-in-production-2024"
JWT_EXPIRES_IN="7d"

# Server
PORT=3000
NODE_ENV=development
CORS_ORIGIN="http://localhost:5173"

# Email (опционально - можно пропустить)
# SMTP_HOST="smtp.gmail.com"
# SMTP_PORT="587"
# SMTP_USER="your-email@gmail.com"
# SMTP_PASS="your-app-password"

# Redis (опционально - можно пропустить)
# REDIS_HOST="localhost"
# REDIS_PORT="6379"
EOF
```

### **Установи зависимости:**

```bash
npm install
```

### **Примени миграции Prisma:**

```bash
# Вариант 1: Создать миграции
npx prisma migrate dev --name init

# Вариант 2: Просто синхронизировать схему
npx prisma db push

# Генерация Prisma Client
npx prisma generate
```

**Ожидаемый вывод:**
```
✔ Generated Prisma Client
```

## 🧪 ТЕСТИРОВАНИЕ API (curl)

### **1. Логин студента:**
```bash
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "student1@lptt.ru",
    "password": "123456"
  }'
```

Сохрани `token` из ответа!

### **2. Получить оценки:**
```bash
curl http://localhost:3000/api/grades/student/STUDENT_ID \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### **3. Расписание группы:**
```bash
curl http://localhost:3000/api/schedule/group/GROUP_ID?dayOfWeek=1 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### **4. Посещаемость:**
```bash
curl http://localhost:3000/api/attendance/student/STUDENT_ID \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## 🔧 TROUBLESHOOTING

### **Проблема: Backend не запускается**

**Решение:**
```bash
# Проверь что Postgres работает
psql -U postgres -d lptt_db

# Проверь DATABASE_URL в .env
cat backend/.env | grep DATABASE_URL

# Пере-генерируй Prisma Client
cd backend
npx prisma generate
```

### **Проблема: "Can't reach database server"**

**Решение:**
```bash
# Проверь что Postgres запущен
brew services list | grep postgresql

# Или
docker ps | grep postgres

# Проверь порт
lsof -i :5432
```

### **Проблема: Seed не работает**

**Решение:**
```bash
# Очисти базу вручную
psql -U postgres -d lptt_db -c "DROP SCHEMA public CASCADE; CREATE SCHEMA public;"

# Примени миграции заново
npx prisma db push

# Запусти seed
npm run seed
```

### **Проблема: Frontend показывает демо-данные**

**Решение:**
```bash
# Проверь что backend запущен на :3000
curl http://localhost:3000/api/health

# Проверь src/services/api.ts
grep "localhost:3000" src/services/api.ts

# Очисти кэш браузера
# Chrome: Cmd+Shift+Delete
```
