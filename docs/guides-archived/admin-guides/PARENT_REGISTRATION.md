# 👨‍👩‍👧 Регистрация и синхронизация родителей с детьми

## 📋 Пошаговая инструкция

---

## Вариант 1: Регистрация родителя администратором

### Шаг 1: Вход в админ панель

1. Войди как администратор:
   - Email: `admin@lptt.ru`
   - Пароль: `123456`

2. Перейди в раздел **"Пользователи"**

### Шаг 2: Создание родителя

1. Нажми **"Создать пользователя"**

2. Заполни форму:
   ```
   ФИО:           Иванов Пётр Васильевич
   Email:         ivanov.parent@lptt.ru
   Пароль:        (генерируется автоматически или задай свой)
   Роль:          Родитель
   ```

3. Нажми **"Создать"**

### Шаг 3: Привязка ребёнка

После создания родителя:

1. Найди созданного родителя в списке
2. Нажми **"Привязать детей"**
3. Выбери студентов из списка:
   ```
   ☑ Иванов Иван Петрович (ИС-21)
   ☐ Петрова Мария Сергеевна (ИС-22)
   ```
4. Нажми **"Сохранить"**

### Шаг 4: Отправка данных родителю

Отправь родителю:
```
Уважаемый Иванов Пётр Васильевич!

Вам создан доступ к электронному дневнику.

Данные для входа:
📧 Email: ivanov.parent@lptt.ru
🔒 Пароль: [пароль]

Сайт: https://diary.lptt.ru

Вы можете отслеживать успеваемость:
👨‍🎓 Иванов Иван Петрович (ИС-21)

С уважением,
Администрация ЛПТТ
```

## Вариант 2: Самостоятельная регистрация родителя

### Шаг 1: Генерация инвайт-кода

Администратор:

1. Перейди в **"Инвайт-коды"**
2. Выбери **"Для родителей"**
3. Нажми **"Сгенерировать"**
4. Скопируй код: `LPTT-PARENT-ABC123XYZ`

### Шаг 2: Регистрация родителя

Родитель:

1. Открой сайт: `https://diary.lptt.ru`
2. Нажми **"Регистрация"**
3. Выбери роль **"Родитель"**
4. Заполни форму:
   ```
   ФИО:          Иванов Пётр Васильевич
   Email:        ivanov.parent@lptt.ru
   Пароль:       [выбери пароль]
   Инвайт-код:   LPTT-PARENT-ABC123XYZ
   ```
5. Нажми **"Зарегистрироваться"**

### Шаг 3: Привязка ребёнка (через админа)

После регистрации родитель отправляет запрос админу:

**Родитель пишет:**
```
Я зарегистрировался как родитель.
Мой email: ivanov.parent@lptt.ru

Прошу привязать моего ребёнка:
Иванов Иван Петрович, группа ИС-21
```

**Администратор:**
1. Находит родителя по email
2. Нажимает **"Привязать детей"**
3. Выбирает студента Иванов Иван Петрович
4. Сохраняет

### Шаг 4: Подтверждение

Родитель получает уведомление:
```
✅ Привязан ребёнок: Иванов Иван Петрович (ИС-21)

Теперь вы можете отслеживать его успеваемость!
```

Создай файл `parents.csv`:


### Импорт через админ панель

1. Войди как администратор
2. Перейди в **"Импорт данных"**
3. Выбери **"Импорт родителей"**
4. Загрузи файл `parents.csv`
5. Система автоматически:
   - Создаст родителей
   - Привяжет детей
   - Отправит email с данными для входа

## 🔧 Управление привязками

### Добавить ещё одного ребёнка:

Администратор:
1. Найди родителя
2. Нажми **"Управление детьми"**
3. Нажми **"Добавить ребёнка"**
4. Выбери студента
5. Сохрани

### Отвязать ребёнка:

Администратор:
1. Найди родителя
2. Нажми **"Управление детьми"**
3. Найди ребёнка в списке
4. Нажми **"Отвязать"**
5. Подтверди

## ⚠️ Важные моменты

### Безопасность:

- ✅ Родитель видит ТОЛЬКО своих детей
- ✅ Родитель НЕ МОЖЕТ редактировать данные
- ✅ Родитель НЕ ВИДИТ других студентов
- ✅ Все действия логируются

### Рекомендации:

1. **Email родителя**
   - Используй реальный email
   - Проверь правильность написания
   - Лучше использовать личный email, а не рабочий

2. **Привязка детей**
   - Проверь правильность данных студента
   - Уточни у студента ФИО родителя
   - Можно привязать нескольких детей к одному родителю

3. **Пароли**
   - Генерируй сложные пароли
   - Отправляй пароль отдельно (не храни в email)
   - Рекомендуй родителю сменить пароль после первого входа
