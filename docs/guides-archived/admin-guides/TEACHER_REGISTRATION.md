# 👨‍🏫 Регистрация преподавателей - Подробная инструкция

## 🎯 Быстрый способ (через админ панель)

### Шаг 1: Вход в систему

1. Войди как администратор:
   - Email: `admin@lptt.ru`
   - Пароль: `123456`

2. Перейди в **"Пользователи"** → **"Создать пользователя"**

### Шаг 2: Заполнение формы

```
┌────────────────────────────────────────┐
│  СОЗДАНИЕ ПРЕПОДАВАТЕЛЯ                │
├────────────────────────────────────────┤
│  ФИО:            Иванова Мария Петровна│
│  Email:          ivanova@lptt.ru       │
│  Пароль:         [генерировать]        │
│  Роль:           Преподаватель         │
│                                        │
│  Должность:      Преподаватель         │
│  Кафедра:        Общеобразовательных   │
│                  дисциплин             │
│  Учёная степень: Кандидат наук         │
│                                        │
│  [Создать]                             │
└────────────────────────────────────────┘
```

### Шаг 3: Назначение предметов

После создания преподавателя:

1. Найди его в списке
2. Нажми **"Назначить предметы"**
3. Выбери предметы из списка:
   ```
   ☑ Математика
   ☑ Физика
   ☐ Информатика
   ☐ История
   ```
4. Нажми **"Сохранить"**

### Шаг 4: Назначение на группы

1. Нажми **"Назначить группы"**
2. Выбери группы:
   ```
   ☑ ИС-21
   ☑ ИС-22
   ☐ АТ-21
   ```
3. Нажми **"Сохранить"**

### Шаг 5: Отправка данных

Отправь преподавателю email:

```
Уважаемая Иванова Мария Петровна!

Вам создан доступ к электронному журналу.

Данные для входа:
📧 Email: ivanova@lptt.ru
🔒 Пароль: [пароль]

Сайт: https://diary.lptt.ru

Ваши предметы:
📚 Математика
📚 Физика

Ваши группы:
👥 ИС-21, ИС-22

При первом входе рекомендуем сменить пароль.

С уважением,
Администрация ЛПТТ
```

## 🎓 Настройка расписания для преподавателя

### Автоматическое создание расписания

Система может создать расписание автоматически:

1. Перейди в **"Расписание"** → **"Автогенерация"**
2. Выбери группу: `ИС-21`
3. Нажми **"Сгенерировать"**

Система:
- Распределит предметы по дням
- Назначит преподавателей
- Исключит конфликты (один преподаватель в разных группах одновременно)
- Сбалансирует нагрузку

### Ручное создание расписания

1. Перейди в **"Расписание"**
2. Выбери группу и день недели
3. Нажми **"Добавить пару"**
4. Заполни:
   ```
   Время:        09:00 - 10:30
   Предмет:      Математика
   Преподаватель: Иванова М.П. (выбирается из назначенных)
   Кабинет:      205
   Тип:          Лекция
   ```
5. Сохрани

## 🔧 Редактирование данных преподавателя

### Изменение основных данных:

1. Найди преподавателя в списке
2. Нажми **"Редактировать"**
3. Измени нужные поля
4. Сохрани

### Изменение предметов:

1. Нажми **"Назначить предметы"**
2. Сними галочки с ненужных
3. Поставь на новые
4. Сохрани

**Важно:** При удалении предмета, удаляется и расписание!

### Изменение групп:

1. Нажми **"Назначить группы"**
2. Измени список групп
3. Сохрани

## 📊 Нагрузка преподавателя

### Просмотр нагрузки:

В карточке преподавателя отображается:

```
┌──────────────────────────────────────┐
│  НАГРУЗКА ПРЕПОДАВАТЕЛЯ              │
├──────────────────────────────────────┤
│  Иванова Мария Петровна              │
│                                      │
│  Часов в неделю:  18                 │
│  Групп:           2                  │
│  Студентов:       49                 │
│                                      │
│  Понедельник:     4 часа             │
│  Вторник:         4 часа             │
│  Среда:           4 часа             │
│  Четверг:         2 часа             │
│  Пятница:         4 часа             │
│  Суббота:         0 часов            │
│                                      │
│  Статус: ✅ Норма (16-20 часов)      │
└──────────────────────────────────────┘
```

### Балансировка нагрузки:

Система предупредит если:
- ⚠️ Нагрузка < 10 часов (недозагрузка)
- ⚠️ Нагрузка > 24 часов (перегрузка)
- ⚠️ Конфликт расписания
