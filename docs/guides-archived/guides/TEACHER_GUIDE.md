# 👨‍🏫 Руководство для преподавателя

Добро пожаловать в систему ЛПТТ Электронный Журнал!

---

## 🔑 Вход в систему

1. Открой сайт электронного дневника
2. Нажми **"Войти"**
3. Введи свои данные:
   - **Email**: твой преподавательский email
   - **Пароль**: пароль от администратора

---

После входа ты увидишь свою панель преподавателя с:

### Быстрый доступ:
- 📅 **Расписание** - твоё расписание на неделю
- 👥 **Студенты** - список всех твоих студентов
- 📚 **Группы** - группы, в которых ты преподаёшь

## 📅 Расписание

### Просмотр расписания:
1. Перейди в раздел **"Расписание"**
2. Увидишь все свои пары на неделю
3. Сгруппировано по дням

### Информация о паре:
- ⏰ **Время** - начало и конец
- 📚 **Предмет** - что преподаёшь
- 👥 **Группа** - какая группа
- 🏫 **Кабинет** - где проходит
- 📌 **Тип** - Лекция, Практика, Лабораторная

---

## 👥 Студенты

### Список студентов:
1. Перейди в раздел **"Студенты"**
2. Увидишь всех студентов по группам
3. Можешь искать по имени

### Информация о студенте:
- 👤 **ФИО** - полное имя

### Действия:
- 📚 Посмотреть все оценки студента

- ✅ Отметить посещаемость

## ✍️ Выставление оценок

### Как выставить оценку:

1. **Способ 1: Через список студентов**
   - Перейди в "Студенты"
   - Найди нужного студента
   - Нажми "Выставить оценку"

2. **Способ 2: Быстрое выставление**
   - Нажми "Выставить оценку" на главной
   - Выбери студента из списка

### Форма оценки:
```
👤 Студент: [Выбрать из списка]
📚 Предмет: [Выбрать из твоих предметов]
⭐ Оценка:  [2, 3, 4, 5]
📌 Тип:     [Экзамен, Контрольная, ДЗ, Практика...]
💬 Комментарий: [Необязательно]
```

### Типы оценок:
- 📝 **Экзамен** - экзаменационная оценка
- 📋 **Контрольная** - контрольная работа
- 📖 **Домашняя работа** - ДЗ
- ⚗️ **Практика** - практическая работа
- 🔬 **Лабораторная** - лабораторная работа
- 📊 **Тест** - тестирование

### После выставления:
- ✅ Оценка сразу отображается у студента
- 📧 Студент получает уведомление
- 📊 Оценка учитывается в статистике

---

## ✅ Отметка посещаемости

### Как отметить посещаемость:

1. **Выбери дату**
   - Выбери день занятия
   - По умолчанию - сегодня

2. **Выбери студента**
   - Найди студента в списке
   - Можно отметить всю группу

3. **Выбери статус**
   - ✅ **Присутствовал** - был на паре
   - ❌ **Отсутствовал** - пропустил
   - ⏰ **Опоздал** - пришёл с опозданием
   - 🏥 **Уважительная причина** - по болезни/документу

4. **Добавь причину** (для пропусков)
   - Болезнь
   - Документ
   - Другое

### Массовая отметка:
- Можно отметить всю группу как "Присутствовал"
- Потом отметить только отсутствующих/опоздавших

## ⚠️ Частые вопросы

### Как исправить ошибочно выставленную оценку?
- Найди оценку в списке
- Нажми "Редактировать"
- Измени значение или удали

### Забыл отметить посещаемость?
- Можно отметить задним числом
- Выбери нужную дату
- Отметь студентов

### Не вижу свою группу?
- Обратись к администратору
- Возможно, тебя не назначили на группу

### Студент жалуется на неправильную оценку?
- Проверь в системе
- Если ошибка - исправь
- Если всё верно - объясни студенту
