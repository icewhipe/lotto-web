## 📊 Отчёты

### Отчёт по успеваемости:

**Параметры:**
- 📅 **Период** - выбрать даты
- 📚 **Специальность** - все или конкретная
- 👥 **Группа** - все или конкретная
- 📊 **Детализация** - по месяцам/неделям

**Содержание отчёта:**

```
┌──────────────────────────────────────────┐
│  ОТЧЁТ ПО УСПЕВАЕМОСТИ                   │
│  Период: 01.09.2024 - 31.12.2024         │
├──────────────────────────────────────────┤
│                                          │
│  Группа    │ Студ. │ Ср.балл │ Динамика│
│──────────┼────────┼─────────┼──────────│
│  ИС-21   │   25   │  4.2    │  ↗ +0.3 │
│  ИС-22   │   24   │  3.9    │  → 0.0  │
│  АТ-21   │   26   │  4.1    │  ↗ +0.2 │
│                                          │
│  ИТОГО:       75      4.07      +0.17   │
└──────────────────────────────────────────┘
```

**Детализация:**
- 🟢 **Отличники** (средний 4.5+)
- 🔵 **Хорошисты** (средний 4.0-4.49)
- 🟡 **Троечники** (средний 3.0-3.99)
- 🔴 **Неуспевающие** (средний <3.0)

**Проблемные зоны:**
- ⚠️ Группы с низким средним баллом
- 📉 Группы с падением успеваемости
- 🔴 Студенты с неудовлетворительными оценками

### Отчёт по посещаемости:

**Содержание:**

```
┌──────────────────────────────────────────┐
│  ОТЧЁТ ПО ПОСЕЩАЕМОСТИ                   │
│  Период: Октябрь 2024                    │
├──────────────────────────────────────────┤
│                                          │
│  Группа  │ Занятий │ Посещ. │ Пропуски│
│──────────┼─────────┼────────┼──────────│
│  ИС-21   │   120   │  92%   │    10   │
│  ИС-22   │   118   │  88%   │    14   │
│  АТ-21   │   122   │  95%   │     6   │
│                                          │
│  СРЕДНЯЯ ПОСЕЩАЕМОСТЬ:        91.7%     │
└──────────────────────────────────────────┘
```

**Анализ:**
- ✅ Группы с высокой посещаемостью (95%+)
- ⚠️ Группы с низкой посещаемостью (<85%)
- 📊 Динамика по дням недели
- 🔴 Систематические прогульщики

### Сравнительный отчёт:

**Сравнение по периодам:**
- 📊 Текущий семестр vs. прошлый семестр
- 📈 Текущий год vs. прошлый год
- 🎯 План vs. факт

**Сравнение по специальностям:**
- 💻 Информационные системы
- 🚗 Автомобильный транспорт
- ⚡ Другие специальности
