# 👨‍👩‍👧 Руководство для родителя

Добро пожаловать в систему контроля успеваемости ЛПТТ!

---

## 🔑 Вход в систему

1. Открой сайт электронного дневника
2. Нажми **"Войти"**
3. Введи свои данные:
   - **Email**: твой email, предоставленный техникумом
   - **Пароль**: пароль от администратора

---

## 👨‍👩‍👧 Мои дети

После входа ты увидишь список своих детей.

### Информация о ребёнке:
- 👤 **ФИО** - полное имя
- 👥 **Группа** - в какой группе учится
- 📚 **Специальность** - направление обучения
- 📊 **Средний балл** - текущая успеваемость

### Быстрые действия:
- 📚 **Оценки** - посмотреть оценки ребёнка
- 👥 **Посещаемость** - проверить посещаемость

## 📚 Оценки ребёнка

### Как посмотреть оценки:
1. Выбери ребёнка из списка
2. Нажми "Оценки"
3. Увидишь все оценки

### Что ты видишь:
- 📚 **Предмет** - название предмета
- ⭐ **Оценка** - балл (2, 3, 4, 5)
- 📅 **Дата** - когда выставлена
- 📌 **Тип** - Экзамен, Контрольная, ДЗ...
- 👨‍🏫 **Преподаватель** - кто выставил

### Фильтр по предметам:
- Нажми на название предмета
- Увидишь только оценки по этому предмету
- Нажми "Все" для возврата

### Статистика:
- 📊 **Средний балл** - общий средний
- 🟢 **Пятёрки** - количество отличных оценок
- 🔵 **Четвёрки** - количество хороших
- 🟡 **Тройки** - количество удовлетворительных
- 🔴 **Двойки** - количество неудовлетворительных

### Цветовая кодировка:
- 🟢 **Зелёный** - пятёрка (5) - отлично!
- 🔵 **Синий** - четвёрка (4) - хорошо
- 🟡 **Жёлтый** - тройка (3) - удовлетворительно
- 🔴 **Красный** - двойка (2) - требует внимания!

---

## 👥 Посещаемость

### Как проверить посещаемость:
1. Выбери ребёнка
2. Нажми "Посещаемость"

### Статистика:
- ✅ **Процент посещаемости** - общий процент
- 📊 **Всего занятий** - количество пар
- 🟢 **Присутствовал** - был на парах
- 🔴 **Пропусков** - пропущено занятий
- 🟡 **Опозданий** - количество опозданий

### Просмотр по датам:
- Записи сгруппированы по дням
- Каждый день показывает все пары
- Статус для каждой пары

### Статусы:
- ✅ **Присутствовал** - зелёный, всё хорошо
- ❌ **Отсутствовал** - красный, был пропуск
- ⏰ **Опоздал** - оранжевый, опоздал на пару
- 🏥 **Уважительная причина** - синий, по документу

### Причины пропусков:
Если ребёнок отсутствовал, может быть указана причина:
- 🏥 **Болезнь**
- 📄 **Документ**
- 👨‍👩‍👧 **Семейные обстоятельства**

## 📅 Расписание

### Как посмотреть расписание:
1. Выбери ребёнка
2. Нажми "Расписание"

### Просмотр по дням:
- Нажми на день недели (Пн, Вт, Ср...)
- Увидишь все пары на этот день

### Информация о паре:
- ⏰ **Время** - начало и конец занятия
- 📚 **Предмет** - что изучает
- 👨‍🏫 **Преподаватель** - кто ведёт
- 🏫 **Кабинет** - где проходит
- 📌 **Тип** - Лекция, Практика, Лабораторная

### Типы занятий:
- 📘 **Лекция** - теоретическое занятие (синий)
- ⚗️ **Практика** - практическое занятие (зелёный)
- 🔬 **Лабораторная** - лабораторная работа (фиолетовый)

---

## 📊 Статистика и аналитика

### Общая статистика:
- 📈 **Динамика оценок** - как меняется средний балл
- 📊 **Распределение оценок** - по предметам
- ✅ **Тенденция посещаемости** - улучшение/ухудшение

### Сравнение с группой:
- 📊 Средний балл ребёнка vs. средний по группе
- ✅ Посещаемость ребёнка vs. средняя по группе

### Проблемные зоны:
Система автоматически выделит:
- 🔴 **Предметы с низким баллом** - требуют внимания
- ⚠️ **Частые пропуски** - проблемы с посещаемостью
- 📉 **Падение успеваемости** - снижение среднего балла

Немедленно обратись к преподавателю/куратору, если:

### Успеваемость:
