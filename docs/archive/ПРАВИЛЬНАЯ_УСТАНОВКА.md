# ✅ ПРАВИЛЬНАЯ УСТАНОВКА ЧЕРЕЗ GIT

## 🚨 ПРОБЛЕМА:

Если ты скачал архив (ZIP) с GitHub:
- ❌ Нет папки `.git`
- ❌ `git pull` не работает
- ❌ Обновления не приходят

---

## ✅ ПРАВИЛЬНЫЙ СПОСОБ:

### 1. Удали старую папку проекта
```bash
cd /Users/vasiliidyahenko/Documents/GitHub
rm -rf lotto-web
```

---

### 2. Клонируй через git
```bash
cd /Users/vasiliidyahenko/Documents/GitHub

git clone https://github.com/icewhipe/lotto-web.git

cd lotto-web
```

---

### 3. Переключись на нужную ветку
```bash
git checkout feature/electronic-diary-optimization
```

---

### 4. Установи зависимости
```bash
npm install

cd backend
npm install
cd ..
```

---

### 5. Запусти
```bash
npm start
```

---

## ✅ ПРОВЕРКА ЧТО GIT РАБОТАЕТ:

```bash
cd /Users/vasiliidyahenko/Documents/GitHub/lotto-web

# Должно показать ветку
git branch
# Должно быть: * feature/electronic-diary-optimization

# Должно показать статус
git status
# Должно быть: Your branch is up to date

# Должно показать коммиты
git log --oneline -3
```

**Если всё показывает → git работает! ✅**
