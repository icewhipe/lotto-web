# 🔑 Как создать тестовый код приглашения

## 3 СПОСОБА (выбери любой):

---

## ✅ СПОСОБ 1: NPM скрипт (САМЫЙ ПРОСТОЙ)

```bash
# 1. Забери обновления
cd /Users/vasiliidyahenko/Documents/GitHub/lotto-web
git pull origin feature/electronic-diary-optimization

# 2. Примени миграцию (если ещё не делал)
cd backend
npx prisma migrate dev --name add_registration_system

# 3. Создай тестовый код
npm run create-invite-code
```

**Результат:**
```
🔑 Creating test invite code...
✅ Test invite code created!

📋 Code details:
Code: TEST-IS21-2024-001
Group: ИС-21
Specialty: Информационные системы
Expires: 2025-12-31

💡 Use this code on registration page!
```

**Теперь используй код:** `TEST-IS21-2024-001`

---

## ✅ СПОСОБ 2: Prisma Studio (ВИЗУАЛЬНЫЙ)

```bash
cd backend
npx prisma studio
```

Откроется http://localhost:5555

### Шаги:
1. Перейди в таблицу `invite_codes`
2. Нажми "Add record"
3. Заполни поля:

```
code:        TEST-IS21-2024-001
groupId:     [Нажми на поле → выбери группу ИС-21]
createdBy:   [Нажми на поле → выбери admin пользователя]
expiresAt:   2025-12-31T23:59:59.000Z
isActive:    true
maxUses:     1
currentUses: 0
```

4. Нажми "Save 1 change"

## ✅ СПОСОБ 3: SQL запрос (ДЛЯ ОПЫТНЫХ)

```bash
# Подключись к PostgreSQL
psql -U vasiliidyahenko -d lptt_db

# Найди ID группы
SELECT id, name FROM groups;

# Найди ID админа
SELECT id, name, email FROM users WHERE role = 'ADMIN';

# Создай код
INSERT INTO invite_codes (
  id, 
  code, 
  "groupId", 
  "createdBy", 
  "expiresAt", 
  "isActive", 
  "maxUses", 
  "currentUses", 
  "createdAt"
) VALUES (
  gen_random_uuid(),
  'TEST-IS21-2024-001',
  '[ВСТАВЬ ID ГРУППЫ]',
  '[ВСТАВЬ ID АДМИНА]',
  '2025-12-31 23:59:59',
  true,
  1,
  0,
  NOW()
);

# Проверь
SELECT * FROM invite_codes;
```
