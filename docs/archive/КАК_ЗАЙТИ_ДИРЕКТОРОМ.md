## 🔧 СПОСОБ 2: Создать директора через Prisma Studio

### Шаг 1: Открой Prisma Studio
```bash
cd backend
npx prisma studio
```

Откроется браузер: `http://localhost:5555`

### Шаг 2: Создай пользователя "Директор"

1. Открой таблицу `User`
2. Нажми `Add record`
3. Заполни поля:
   ```
   id: (автоматически)
   email: director@lptt.ru
   password: (нужен хэш) - см. ниже
   name: Иванов Иван Иванович
   role: ADMIN (пока так, потом добавим роль DIRECTOR)
   isActive: true
   ```

### Шаг 3: Получи хэш пароля

Открой терминал и выполни:
```bash
cd backend
node -e "const bcrypt = require('bcryptjs'); console.log(bcrypt.hashSync('123456', 10))"
```

Скопируй полученный хэш и вставь в поле `password`

### Шаг 4: Сохрани
Нажми `Save 1 change`

## 🚀 СПОСОБ 3: Через консоль Node.js (БЫСТРЫЙ!)

В терминале выполни:

```bash
cd backend
node
```

В консоли Node.js вставь:

```javascript
const { PrismaClient } = require('@prisma/client');
const bcrypt = require('bcryptjs');

const prisma = new PrismaClient();

async function createDirector() {
  const hashedPassword = await bcrypt.hash('123456', 10);
  
  const director = await prisma.user.create({
    data: {
      email: 'director@lptt.ru',
      password: hashedPassword,
      name: 'Иванов Иван Иванович',
      role: 'ADMIN', // Используем ADMIN пока нет роли DIRECTOR
      isActive: true,
    }
  });
  
  console.log('✅ Директор создан!', director);
  await prisma.$disconnect();
}

createDirector();
```

Потом нажми `Ctrl+D` чтобы выйти

## 📝 СПОСОБ 4: Создать скрипт

Создай файл `backend/createDirector.js`:

```javascript
const { PrismaClient } = require('@prisma/client');
const bcrypt = require('bcryptjs');

const prisma = new PrismaClient();

async function main() {
  const hashedPassword = await bcrypt.hash('123456', 10);
  
  const director = await prisma.user.create({
    data: {
      email: 'director@lptt.ru',
      password: hashedPassword,
      name: 'Иванов Иван Иванович',
      role: 'ADMIN',
      isActive: true,
    }
  });
  
  console.log('✅ Директор создан!');
  console.log('📧 Email:', director.email);
  console.log('🔑 Пароль: 123456');
  console.log('👤 Имя:', director.name);
}

main()
  .catch(console.error)
  .finally(() => prisma.$disconnect());
```

Запусти:
```bash
node backend/createDirector.js
```

## 🎯 СПОСОБ 5: Обновить seed скрипт (РЕКОМЕНДУЕТСЯ!)

Открой `backend/src/utils/seedDatabase.ts` и добавь:

```typescript
// После создания админа
const directorPassword = await bcrypt.hash('123456', 10);
const director = await prisma.user.create({
  data: {
    email: 'director@lptt.ru',
    password: directorPassword,
    name: 'Петров Петр Петрович',
    role: 'ADMIN', // Или создай новую роль DIRECTOR в schema.prisma
  },
});

console.log('✅ Created director');
```

Потом запусти seed:
```bash
cd backend
npx prisma migrate reset  # Очистит БД и заново создаст данные
# ИЛИ
npm run seed
```

## ⚠️ ВАЖНО!

### Если хочешь отдельную роль DIRECTOR:

Обновы `backend/prisma/schema.prisma`:

```prisma
enum UserRole {
  STUDENT
  TEACHER
  PARENT
  APPLICANT
  ADMIN
  DIRECTOR  // ← Добавь это
  ZAVUCH    // ← И это для завуча
}
```

Потом выполни миграцию:
```bash
cd backend
npx prisma migrate dev --name add_director_role
```
