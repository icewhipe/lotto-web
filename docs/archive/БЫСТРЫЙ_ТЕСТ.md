## ❌ ЕСЛИ НЕ РАБОТАЕТ:

### Консоль (F12) показывает ошибку?
→ Скопируй ошибку и скинь мне

### Не видишь кнопку "Создать пользователя"?
→ Проверь, что ты вошёл как админ

### Пользователь создался, но не можешь войти?
→ Открой консоль (F12) и выполни:
```javascript
console.log(localStorage.getItem('user_credentials'))
```
→ Должен увидеть созданных пользователей

### Вообще всё сломалось?
```javascript
// В консоли (F12):
localStorage.clear()
location.reload()
// Потом заново создай пользователей
```
