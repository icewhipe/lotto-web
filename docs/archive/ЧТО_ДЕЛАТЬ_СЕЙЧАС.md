## 3️⃣ СОЗДАЙ ТЕСТОВЫЙ КОД:

### Через Prisma Studio:
```bash
npx prisma studio
```

Откроется http://localhost:5555

1. Таблица "groups" → найди "ИС-21" → скопируй ID
2. Таблица "users" → найди ADMIN → скопируй ID
3. Таблица "invite_codes" → "Add record":
   ```
   code: TEST-IS21-2024-001
   groupId: [вставь ID группы]
   createdBy: [вставь ID админа]
   expiresAt: 2025-12-31T23:59:59.000Z
   isActive: true
   maxUses: 1
   currentUses: 0
   ```
4. "Save 1 change"
