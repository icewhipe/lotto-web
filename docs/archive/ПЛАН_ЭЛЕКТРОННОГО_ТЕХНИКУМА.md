## 🏛️ РОЛИ И ФУНКЦИИ

### 1. 👨‍💼 **ДИРЕКТОР** (Высший уровень управления)

#### Аналитика и отчётность:
- 📊 **Общая статистика техникума:**
  - Количество студентов (всего, по курсам, по специальностям)
  - Количество преподавателей
  - Количество групп
  - Средний балл по техникуму
  - Общая посещаемость
  - Количество абитуриентов

- 📈 **Динамика показателей:**
  - График изменения успеваемости за год
  - График посещаемости за год
  - Сравнение курсов между собой
  - Тренды и прогнозы

- 🏆 **Рейтинги:**
  - Топ-10 лучших студентов
  - Топ-5 лучших групп (по среднему баллу)
  - Топ-5 лучших преподавателей (по отзывам студентов)
  - Рейтинг специальностей (востребованность, успеваемость)

- 💰 **Финансовые показатели:**
  - Оплата обучения (сколько оплатили, сколько должны)
  - Бюджет на зарплаты
  - Расходы на оборудование
  - Прогноз доходов

#### Управление:
- 👥 **Управление персоналом:**
  - Просмотр всех сотрудников
  - Назначение/снятие ролей
  - Контроль рабочего времени
  - Отпуска и больничные

- 📋 **Документооборот:**
  - Приказы и распоряжения
  - Утверждение учебных планов
  - Подписание документов
  - Архив документов

- 🎯 **Стратегическое планирование:**
  - Постановка целей на год
  - KPI для завучей и преподавателей
  - Планы развития техникума

- 🔔 **Уведомления и контроль:**
  - Критические события (ЧП, конфликты)
  - Важные собрания
  - Проверки и аудиты
  - Обращения от родителей

#### Отчёты:
- 📄 Отчёт по успеваемости за семестр/год
- 📄 Отчёт по посещаемости
- 📄 Отчёт о трудоустройстве выпускников
- 📄 Отчёт о поступлении (абитуриенты)
- 📄 Финансовый отчёт

### 2. 📚 **ЗАВУЧ** (Управление учебным процессом)

#### Основные функции:

**Расписание:**
- 📅 **Составление расписания:**
  - Создание расписания для всех групп
  - Назначение преподавателей на занятия
  - Распределение кабинетов
  - Учёт нагрузки преподавателей
  - Замены при болезни/отпуске

- 🔄 **Управление заменами:**
  - Список преподавателей на больничном
  - Автоподбор замены
  - Уведомления студентов о заменах

**Учебный процесс:**
- 📖 **Учебные планы:**
  - Утверждение учебных планов по специальностям
  - Распределение часов по дисциплинам
  - Контроль выполнения программы

- 📝 **Контроль успеваемости:**
  - Общая картина по всем группам
  - Списки должников
  - Студенты группы риска (много пропусков)
  - Мониторинг выставления оценок преподавателями

- 👨‍🏫 **Работа с преподавателями:**
  - Нагрузка преподавателей (часы)
  - Методическая работа
  - Повышение квалификации
  - Аттестация

**Мониторинг:**
- 📊 **Аналитика по группам:**
  - Средний балл каждой группы
  - Посещаемость по группам
  - Динамика успеваемости
  - Проблемные группы

- 🎓 **Экзамены и сессия:**
  - Расписание экзаменов
  - Ведомости
  - Результаты сессии
  - Допуск к экзаменам

**Отчёты:**
- 📄 Отчёт по успеваемости групп
- 📄 Отчёт о выполнении учебного плана
- 📄 Отчёт о нагрузке преподавателей
- 📄 Отчёт о заменах
- 📄 Отчёт об экзаменах

## 🔄 ВЗАИМОДЕЙСТВИЯ МЕЖДУ РОЛЯМИ

### Директор ↔ Завуч:
- Директор утверждает учебные планы, предложенные завучем
- Завуч отчитывается директору о ходе учебного процесса
- Директор ставит задачи завучу
- Завуч предоставляет аналитику директору

### Директор ↔ Администратор:
- Администратор создаёт пользователей по запросу директора
- Администратор предоставляет технические отчёты
- Директор утверждает системные изменения

### Завуч ↔ Преподаватель:
- Завуч назначает преподавателей на занятия
- Завуч контролирует выставление оценок
- Преподаватель отчитывается о выполнении программы
- Завуч организует замены

### Преподаватель ↔ Студент:
- Преподаватель выставляет оценки студенту
- Преподаватель отмечает посещаемость
- Студент видит оценки и комментарии
- Студент сдаёт работы преподавателю

### Преподаватель ↔ Родитель:
- Родитель видит оценки, выставленные преподавателем
- Родитель может написать преподавателю
- Преподаватель может уведомить родителя о проблемах

### Студент ↔ Родитель:
- Родитель видит все данные студента
- Родитель получает уведомления о студенте

### Администратор ↔ Все:
- Администратор создаёт учётные записи всем
- Администратор помогает со входом (сброс пароля)
- Администратор модерирует контент

## 🎨 ЕДИНЫЙ ДИЗАЙН СИСТЕМЫ

### Цветовая схема (унифицированная):

**Основные цвета:**
```
Фон: bg-gray-50 dark:bg-gray-950 (светлая/тёмная тема)
Карточки: glass-effect (полупрозрачный белый)
Текст: text-gray-900 dark:text-white
```

**Акцентные цвета по ролям:**
- 👨‍💼 Директор: Золотой (amber-500 → yellow-600)
- 📚 Завуч: Зелёный (green-500 → emerald-600)
- ⚙️ Админ: Красный (red-500 → rose-600)
- 👨‍🏫 Преподаватель: Синий (blue-500 → cyan-600)
- 👨‍🎓 Студент: Фиолетовый (violet-500 → purple-600)
- 👨‍👩‍👦 Родитель: Розовый (pink-500 → rose-600)
- 🎓 Абитуриент: Индиго (indigo-500 → purple-600)

**Единый стиль карточек:**
```css
.glass-effect {
  background: rgba(255, 255, 255, 0.7);
  backdrop-filter: blur(10px);
  border: 1px solid rgba(255, 255, 255, 0.3);
  border-radius: 1.5rem;
}
```
