# 🚀 Как запустить систему регистрации

## 📋 Шаги для внедрения регистрации по кодам

### 1️⃣ Забрать обновления
```bash
cd /Users/vasiliidyahenko/Documents/GitHub/lotto-web
git pull origin feature/electronic-diary-optimization
npm install
```

### 2️⃣ Применить миграцию базы данных
```bash
cd backend
npx prisma migrate dev --name add_registration_system
```

**Что создастся:**
- Таблица `invite_codes`
- Таблица `registration_requests`
- Enum `RegistrationStatus`
- Новые связи в существующих таблицах

### 3️⃣ Перезапустить backend
```bash
# Если backend запущен через npm start - он перезапустится автоматически
# Если вручную:
cd backend
npm run dev
```

### 4️⃣ Открыть Prisma Studio (опционально)
```bash
cd backend
npx prisma studio
```

Откроется http://localhost:5555 - можно смотреть БД визуально

## 🧪 Тестирование регистрации

### A) Сгенерировать тестовый код приглашения (через Prisma Studio):

1. Открой Prisma Studio: `npx prisma studio`
2. Перейди в таблицу `invite_codes`
3. Нажми "Add record"
4. Заполни:
   - code: `LPTT-IS21-2024-001`
   - groupId: `[ID группы из таблицы groups]`
   - createdBy: `[ID админа из таблицы users]`
   - expiresAt: `2025-12-31T23:59:59.000Z`
   - isActive: `true`
   - maxUses: `1`
   - currentUses: `0`
5. Сохрани

### B) Или через curl:

```bash
# 1. Войти как админ
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@lptt.ru","password":"123456"}'

# Скопируй token из ответа

# 2. Сгенерировать коды
curl -X POST http://localhost:3000/api/registration/invite-codes/generate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -d '{
    "groupId": "YOUR_GROUP_ID",
    "count": 10,
    "expiresInDays": 30
  }'
```

### C) Тестирование регистрации через UI:

1. Открой http://localhost:5173
2. Нажми кнопку "Регистрация" в navbar
3. Введи код: `LPTT-IS21-2024-001`
4. Нажми "Продолжить"
5. Должно показать: "✅ Группа: ИС-21"
6. Заполни форму:
   - ФИО: Тестовый Студент
   - Email: test@example.com
   - Телефон: +79001234567
   - Дата рождения: 2006-01-01
   - Пароль: test123456
   - Повтор: test123456
7. Нажми "Зарегистрироваться"
8. Должно показать: "✅ Регистрация успешна!"
9. Нажми "Перейти ко входу"
10. Войди с новым email/паролем

## 🎯 API Endpoints

### PUBLIC (без токена):

```bash
# Проверить код приглашения
POST /api/registration/check-invite-code
Body: { "code": "LPTT-IS21-2024-001" }

# Регистрация с кодом
POST /api/registration/register-with-invite
Body: {
  "code": "LPTT-IS21-2024-001",
  "name": "Иван Иванов",
  "email": "ivan@example.com",
  "password": "secure_password",
  "phone": "+79001234567",
  "birthDate": "2006-05-15"
}
```

### ADMIN (с токеном):

```bash
# Сгенерировать коды
POST /api/registration/invite-codes/generate
Headers: { "Authorization": "Bearer TOKEN" }
Body: {
  "groupId": "uuid-группы",
  "count": 30,
  "expiresInDays": 30
}

# Получить все коды
GET /api/registration/invite-codes
Headers: { "Authorization": "Bearer TOKEN" }

# Получить заявки на регистрацию
GET /api/registration/requests?status=PENDING
Headers: { "Authorization": "Bearer TOKEN" }

# Утвердить заявку
POST /api/registration/requests/:requestId/approve
Headers: { "Authorization": "Bearer TOKEN" }
Body: { "groupId": "uuid-группы" }

# Отклонить заявку
POST /api/registration/requests/:requestId/reject
Headers: { "Authorization": "Bearer TOKEN" }
Body: { "reason": "Причина отклонения" }
```
