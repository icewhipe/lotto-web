# 👥 ИНСТРУКЦИЯ: Как создать Директора и Завуча

## ✅ ЧТО СДЕЛАНО:

### 1. **Рабочий менеджер пользователей**
- Админ панель → Пользователи
- Можно создавать ЛЮБЫХ пользователей
- Можно создавать Директора и Завуча
- Всё работает БЕЗ backend!

### 2. **Система входа обновлена**
- Сначала проверяются локальные пользователи
- Потом проверяется backend
- Созданные пользователи работают сразу!

---

## 🚀 КАК СОЗДАТЬ ДИРЕКТОРА:

### Шаг 1: Войди как админ
```
Email: admin@lptt.ru
Пароль: 123456
```

### Шаг 2: Открой "Пользователи"
- Слева в меню нажми **"Пользователи"**

### Шаг 3: Создай директора
- Нажми **"Создать пользователя"** (красная кнопка справа вверху)
- Заполни:
  ```
  Имя: Иванов Иван Иванович
  Email: director@lptt.ru
  Пароль: 123456 (или свой)
  Роль: 👑 Директор
  ```
- Нажми **"Создать пользователя"**

### Шаг 4: Выйди и войди директором
- Выйди (кнопка внизу слева)
- Войди:
  ```
  Email: director@lptt.ru
  Пароль: 123456
  ```
- **БУМ! Ты директор!** 🎉

## 🔐 ГДЕ ХРАНЯТСЯ ДАННЫЕ:

### localStorage (временно):
- `all_users` - список всех пользователей
- `user_credentials` - пароли пользователей

**⚠️ ВАЖНО:**
- Это временное решение БЕЗ backend
- При подключении backend - всё переедет в БД
- Сейчас работает локально в браузере

## 🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

### 1. Очисти кэш браузера:
```
Ctrl+Shift+Delete → Очистить всё
```

### 2. Перезагрузи страницу:
```
Ctrl+R (или F5)
```

### 3. Проверь консоль (F12):
```
Должно быть:
✅ Вход через локальные credentials: {name: "...", role: "..."}
```

### 4. Если всё сломалось:
```javascript
// Открой консоль (F12) и выполни:
localStorage.clear()
location.reload()

// Потом заново войди как админ и создай пользователей
```
