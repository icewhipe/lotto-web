# 🔑 САМЫЙ ПРОСТОЙ СПОСОБ - Через Prisma Studio

## ⚡ ПОШАГОВАЯ ИНСТРУКЦИЯ:

### Шаг 1: Открой Prisma Studio
```bash
cd /Users/vasiliidyahenko/Documents/GitHub/lotto-web/backend
npx prisma studio
```

Откроется: http://localhost:5555

---

### Шаг 2: Найди ID группы

1. В Prisma Studio слева выбери таблицу **"groups"**
2. Найди группу **"ИС-21"** (или любую другую)
3. **СКОПИРУЙ ID** (например: `e0e7adaf-d7ba-412e-95eb-65182f249d7d`)

---

### Шаг 3: Найди ID админа

1. В Prisma Studio слева выбери таблицу **"users"**
2. Найди пользователя с **role = ADMIN**
3. **СКОПИРУЙ ID** (например: `c5f9e8d1-a234-4567-89ab-cdef01234567`)

---

### Шаг 4: Создай код

1. В Prisma Studio слева выбери таблицу **"invite_codes"**
2. Нажми кнопку **"Add record"** (справа вверху)
3. Заполни поля:

```
id:          [оставь пустым - сгенерируется автоматически]
code:        TEST-IS21-2024-001
groupId:     [ВСТАВЬ ID группы из Шага 2]
usedBy:      [оставь пустым]
usedAt:      [оставь пустым]
expiresAt:   2025-12-31T23:59:59.000Z
createdBy:   [ВСТАВЬ ID админа из Шага 3]
isActive:    true
maxUses:     1
currentUses: 0
```

4. Нажми **"Save 1 change"** (зелёная кнопка справа внизу)

---

### Шаг 5: Проверь код

В таблице **"invite_codes"** должна появиться новая запись:
```
✅ code: TEST-IS21-2024-001
✅ isActive: true
✅ currentUses: 0
```

---

## 🎯 ГОТОВО! ИСПОЛЬЗУЙ КОД!

### Теперь на сайте:

1. Открой http://localhost:5173
2. Нажми **"Вход"**
3. Нажми **"Нет аккаунта? Зарегистрироваться"**
4. Введи код: **TEST-IS21-2024-001**
5. Нажми **"Продолжить"**

**Должно показать:**
```
✅ Группа: ИС-21
Специальность: Информационные системы
```

6. Заполни форму регистрации
7. Зарегистрируйся!
