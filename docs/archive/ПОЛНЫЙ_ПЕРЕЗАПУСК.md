### 1. Останови сервер ПОЛНОСТЬЮ
```bash

lsof -ti:5173 | xargs kill -9
lsof -ti:3000 | xargs kill -9
```

### 2. Удали ВСЕ кэши
```bash
cd /Users/vasiliidyahenko/Documents/GitHub/lotto-web

rm -rf node_modules/.vite

```

### 3. Забери обновления ЕЩЁ РАЗ

```bash

```
