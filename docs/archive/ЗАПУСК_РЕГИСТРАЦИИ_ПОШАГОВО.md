## 🧪 ТЕСТ 2: Создай тестовый код

### Вариант A: Через Prisma Studio
```bash
cd backend
npx prisma studio
```

1. Открой http://localhost:5555
2. Перейди в таблицу `invite_codes`
3. Нажми "Add record"
4. Заполни:
   - code: `TEST-IS21-2024-001`
   - groupId: [скопируй ID группы ИС-21 из таблицы groups]
   - createdBy: [скопируй ID админа из таблицы users]
   - expiresAt: `2025-12-31`
   - isActive: `true`
   - maxUses: `1`
   - currentUses: `0`
5. Сохрани
