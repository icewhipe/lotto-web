# 🔍 Диагностика проблемы с электронным дневником

## Что я исправил:

### 1. ✅ AuthContext (ГЛАВНОЕ ИСПРАВЛЕНИЕ!)
**Проблема:** При обновлении страницы, если backend недоступен, пользователь автоматически разлогинивался.

**Исправление:** Теперь при недоступности backend данные восстанавливаются из localStorage.

### 2. ✅ Добавлено debug логирование
Теперь в консоли браузера будут видны подробные логи что происходит.

### 3. ✅ Пересобран проект
Новая сборка: `dist/assets/index-Cnj3TyQ4.js`

## 🐛 Что проверить если не работает:

### Проверка 1: Видны ли вкладки в меню?
Открой дашборд и посмотри на левое боковое меню. Должны быть видны:
- ✅ Главная
- ✅ Расписание
- ✅ Оценки
- ✅ Посещаемость
- ✅ Конспекты
- ✅ Прогресс
- ✅ Чат
- ✅ Документы

**Если НЕ видны** - проблема в DashboardLayout или роли пользователя.

### Проверка 2: Что в консоли?
Открой консоль (F12) и посмотри логи. Отправь мне скриншот или текст!

**Что должно быть:**
```javascript
🔍 Dashboard render: {user: {...}, activeTab: "dashboard"}
✅ User is student/parent, activeTab: dashboard
📱 Rendering StudentDashboard
```

**Если видишь ошибки** - напиши какие!

### Проверка 3: Что в localStorage?
Открой консоль и выполни:
```javascript
console.log('Token:', localStorage.getItem('token'))
console.log('User:', JSON.parse(localStorage.getItem('user')))
```

**Должно быть:**
```json
Token: "mock_jwt_token_1728..."
User: {
  id: "1",
  name: "Иван Петров",
  email: "student@lptt.ru",
  role: "student",
  groupId: "ПТ-21",
  avatar: "👨‍🎓"
}
```

**Если role НЕ "student"** - это проблема!

### Проверка 4: Какая роль у пользователя?
В консоли выполни:
```javascript
// В React DevTools найди AuthContext или выполни:
console.log(JSON.parse(localStorage.getItem('user')).role)
```

Должно быть: **"student"**

### Проверка 5: Переключаются ли табы?
1. Нажми на "Оценки" в меню
2. Посмотри в консоль - должен быть лог:
```
🔍 Dashboard render: {user: {...}, activeTab: "grades"}
✅ User is student/parent, activeTab: grades
📚 Rendering GradesView
```

**Если activeTab НЕ меняется** - проблема с DashboardLayout.
