## 🚀 КАК ПРОТЕСТИРОВАТЬ:

### БЫСТРЫЙ ТЕСТ (2 минуты):

1. **Очисти кэш браузера:**
   ```
   Ctrl+Shift+Delete → Очистить всё
   ```

2. **Запусти проект:**
   ```bash
   npm run dev
   ```

3. **Войди как админ:**
   ```
   Email: admin@lptt.ru
   Пароль: 123456
   ```

4. **Открой "Пользователи"** (слева в меню)

5. **Создай директора:**
   - Нажми "Создать пользователя"
   - Заполни:
     ```
     Имя: Директор Техникума
     Email: director@lptt.ru
     Пароль: 123456
     Роль: 👑 Директор
     ```
   - Нажми "Создать"

6. **Создай завуча:**
   ```
   Имя: Завуч Техникума
   Email: zavuch@lptt.ru
   Пароль: 123456
   Роль: 💼 Завуч
   ```

7. **Выйди и войди директором:**
   ```
   director@lptt.ru / 123456
   ```

8. **ДОЛЖЕН УВИДЕТЬ:**
   - 🟡 Золотую панель директора
   - 📊 8 карточек статистики
   - 📈 Графики
   - 🏆 Топ-5 групп
   - ⭐ Топ-10 студентов

9. **Выйди и войди завучем:**
   ```
   zavuch@lptt.ru / 123456
   ```

10. **ДОЛЖЕН УВИДЕТЬ:**
    - 🟢 Зелёную панель завуча
    - 📅 Замены на сегодня
    - ⚠️ Проблемные группы
    - 👨‍🏫 Нагрузка преподавателей
    - 📊 Графики успеваемости
