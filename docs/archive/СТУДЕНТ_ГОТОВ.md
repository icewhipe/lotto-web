## 🚀 КАК ПРОТЕСТИРОВАТЬ:

### 1. Запусти backend:
```bash
cd backend
npm run dev
# Должен работать на localhost:3000
```

### 2. Запусти frontend:
```bash
npm run dev
# localhost:5173
```

### 3. Очисти кэш:
```
Cmd+Shift+Delete (Mac)
```

### 4. Войди студентом:
```
Email: student@lptt.ru
Пароль: 123456
```

### 5. Тестируй вкладки:

#### **ГЛАВНАЯ:**
- Увидишь статистику
- Графики
- Быстрые действия
- **Нажми на любую кнопку** → перейдёшь на нужную вкладку!

#### **ОЦЕНКИ:**
- Нажми "Оценки" в меню или в быстрых действиях
- Увидишь:
  - Средний балл 4.6
  - Статистику (8 оценок, 5 пятёрок...)
  - Фильтр по предметам ← **Кликабельно!**
  - Список всех оценок с деталями

#### **ПОСЕЩАЕМОСТЬ:**
- Нажми "Посещаемость"
- Увидишь:
  - Процент 87.5%
  - Статистику (8 занятий, 6 был, 1 пропуск, 1 опоздание)
  - Список по датам с цветными статусами

#### **РАСПИСАНИЕ:**
- Нажми "Расписание"
- Увидишь:
  - Табы дней недели ← **Кликабельно!**
  - Нажми на любой день → увидишь расписание
  - Пары с преподавателями, кабинетами, типами
