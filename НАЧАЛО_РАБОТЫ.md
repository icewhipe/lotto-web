## 🖥️ Требования к системе

### Минимальные требования:

- **Операционная система:** Windows 10/11, macOS 10.15+, или Linux
- **Процессор:** 2 ядра, 2 GHz
- **ОЗУ:** 4 GB (рекомендуется 8 GB)
- **Свободное место:** 5 GB
- **Интернет:** Стабильное подключение

### Необходимое ПО:

- **Node.js:** v18.0.0 или выше
- **npm:** v9.0.0 или выше (устанавливается с Node.js)
- **Git:** v2.30.0 или выше
- **PostgreSQL:** v14.0 или выше (для backend)
- **Редактор кода:** VS Code (рекомендуется)

## 📦 Установка необходимого ПО

### 1. Установка Node.js и npm

#### Windows:

1. Скачайте установщик с [nodejs.org](https://nodejs.org/)
2. Запустите установщик (`node-v18.x.x-x64.msi`)
3. Следуйте инструкциям мастера установки
4. Перезагрузите компьютер

#### macOS:

```bash
# Используя Homebrew (рекомендуется)
brew install node

# Или скачайте установщик с nodejs.org
```

#### Linux (Ubuntu/Debian):

```bash
# Добавить репозиторий NodeSource
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -

# Установить Node.js
sudo apt-get install -y nodejs

# Проверить установку
node --version
npm --version
```

### 2. Установка Git

#### Windows:

1. Скачайте установщик с [git-scm.com](https://git-scm.com/)
2. Запустите установщик
3. Используйте настройки по умолчанию

#### macOS:

```bash
# Используя Homebrew
brew install git

# Или используйте Xcode Command Line Tools
xcode-select --install
```

#### Linux (Ubuntu/Debian):

```bash
sudo apt-get update
sudo apt-get install git
```

**Проверка установки Git:**

```bash
git --version
# Должно вывести: git version 2.x.x
```

### 3. Установка PostgreSQL

#### Windows:

1. Скачайте установщик с [postgresql.org](https://www.postgresql.org/download/windows/)
2. Запустите установщик
3. Запомните пароль для пользователя `postgres`

#### macOS:

```bash
# Используя Homebrew
brew install postgresql@14
brew services start postgresql@14
```

#### Linux (Ubuntu/Debian):

```bash
sudo apt-get update
sudo apt-get install postgresql postgresql-contrib
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

### 4. Установка VS Code (рекомендуется)

1. Скачайте с [code.visualstudio.com](https://code.visualstudio.com/)
2. Установите следующие расширения:
   - ESLint
   - Prettier
   - Tailwind CSS IntelliSense
   - GitLens
   - Auto Rename Tag
   - Path Intellisense

## 📥 Клонирование репозитория

### Вариант 1: HTTPS (простой способ)

```bash
# Перейдите в папку, где хотите разместить проект
cd ~/Documents  # для macOS/Linux
cd C:\Users\ВашеИмя\Documents  # для Windows

# Клонируйте репозиторий
git clone https://github.com/lptt/website.git

# Перейдите в папку проекта
cd website
```

### Вариант 2: SSH (безопаснее, требует настройки)

**Сначала настройте SSH ключ:**

```bash
# Создайте SSH ключ (если еще не создан)
ssh-keygen -t ed25519 -C "your_email@example.com"

# Нажмите Enter 3 раза (используйте настройки по умолчанию)

# Скопируйте публичный ключ
# Windows:
type ~/.ssh/id_ed25519.pub

# macOS/Linux:
cat ~/.ssh/id_ed25519.pub

# Добавьте ключ на GitHub:
# 1. Откройте github.com → Settings → SSH and GPG keys
# 2. Нажмите "New SSH key"
# 3. Вставьте скопированный ключ
# 4. Нажмите "Add SSH key"
```

**Теперь клонируйте репозиторий:**

```bash
git clone git@github.com:lptt/website.git
cd website
```

### Проверка клонирования

```bash
# Посмотрите структуру проекта
ls -la  # macOS/Linux
dir     # Windows

# Должны увидеть:
# - backend/
# - src/
# - package.json
# - README.md
# и другие файлы
```

## ⚙️ Настройка проекта

### 1. Установка зависимостей

```bash
# Находясь в корневой папке проекта (website/)

# Установить зависимости frontend
npm install

# Перейти в backend и установить зависимости
cd backend
npm install
cd ..
```

**Это может занять 5-10 минут при первом запуске.**

### 2. Настройка базы данных

#### Создайте базу данных PostgreSQL:

```bash
# Войдите в PostgreSQL
# Windows:
psql -U postgres

# macOS/Linux:
sudo -u postgres psql

# В консоли PostgreSQL выполните:
CREATE DATABASE lptt_db;
CREATE USER lptt_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE lptt_db TO lptt_user;
\q  # Выход
```

#### Создайте файл `.env` в папке `backend/`:

```bash
# Перейдите в папку backend
cd backend

# Создайте .env файл
# Windows (PowerShell):
New-Item .env

# macOS/Linux:
touch .env
```

**Откройте файл `.env` и добавьте:**

```env
# Database
DATABASE_URL="postgresql://lptt_user:your_password@localhost:5432/lptt_db"

# JWT
JWT_SECRET="your_super_secret_jwt_key_change_this_in_production"

# Server
PORT=3000
NODE_ENV=development

# Frontend URL (for CORS)
FRONTEND_URL="http://localhost:5173"

# Optional: Redis (если используется)
# REDIS_URL="redis://localhost:6379"

# Email (опционально, для уведомлений)
# EMAIL_HOST="smtp.gmail.com"
# EMAIL_PORT=587
# EMAIL_USER="your_email@gmail.com"
# EMAIL_PASSWORD="your_app_password"
```

**⚠️ ВАЖНО:** Замените `your_password` на ваш реальный пароль от PostgreSQL!

### 3. Создайте файл `.env` в корне проекта (для frontend):

```bash
# Вернитесь в корень проекта
cd ..

# Создайте .env файл
# Windows (PowerShell):
New-Item .env

# macOS/Linux:
touch .env
```

**Откройте файл `.env` и добавьте:**

```env
# API URL
VITE_API_URL=http://localhost:3000/api

# CDN URL (опционально)
# VITE_CDN_URL=https://cdn.lptt.obrvrn.ru

# Analytics (опционально)
# VITE_ANALYTICS_ID=G-XXXXXXXXXX
```

### 4. Инициализация базы данных

```bash
# Перейдите в папку backend
cd backend

# Сгенерируйте Prisma Client
npx prisma generate

# Примените миграции
npx prisma migrate dev --name init

# (Опционально) Заполните тестовыми данными
npm run seed

# Вернитесь в корень
cd ..
```

## 🚀 Запуск проекта

### Вариант 1: Запуск backend и frontend отдельно (2 терминала)

**Терминал 1 - Backend:**

```bash
# Перейдите в папку backend

# Запустите backend сервер
npm run dev
```


3. Вы должны увидеть **Liquid Glass анимацию** заглушки
4. Затем появится главная страница ЛПТТ

## 🔧 Работа с Git

### Базовые команды Git

#### Проверка статуса:

```bash
# Посмотреть, какие файлы изменены
git status
```

#### Создание новой ветки:

```bash
# Создать и переключиться на новую ветку
git checkout -b feature/my-new-feature

# Альтернативный способ (Git 2.23+)
git switch -c feature/my-new-feature
```

#### Сохранение изменений (commit):

```bash
# Добавить все изменённые файлы
git add .

# Или добавить конкретный файл
git add src/components/MyComponent.tsx

# Создать commit с описанием
git commit -m "feat: добавил новый компонент MyComponent"

# Примеры хороших commit messages:
# feat: добавил форму регистрации
# fix: исправил баг с навигацией
# style: улучшил отступы в Header
# docs: обновил README
# refactor: переписал логику авторизации
```

#### Отправка изменений на GitHub:

```bash
# Отправить текущую ветку
git push origin feature/my-new-feature

# При первой отправке новой ветки
git push -u origin feature/my-new-feature
```

#### Получение изменений с GitHub:

```bash
# Получить последние изменения
git pull origin main

# Или
git fetch origin
git merge origin/main
```

#### Переключение между ветками:

```bash
# Посмотреть все ветки
git branch -a

# Переключиться на другую ветку
git checkout main
# или
git switch main
```

#### Слияние веток (merge):

```bash
# Переключитесь на main
git checkout main

# Получите последние изменения
git pull origin main

# Слейте свою ветку
git merge feature/my-new-feature

# Отправьте изменения
git push origin main
```

### Git Workflow (рекомендуемый)

```bash
# 1. Убедитесь, что вы на main и она обновлена
git checkout main
git pull origin main

# 2. Создайте новую ветку для задачи
git checkout -b feature/add-contact-form

# 3. Работайте над задачей, делайте commits
git add .
git commit -m "feat: добавил форму контактов"

# 4. Отправьте ветку на GitHub
git push -u origin feature/add-contact-form

# 5. Создайте Pull Request на GitHub
# - Откройте github.com/lptt/website
# - Нажмите "Compare & pull request"
# - Опишите изменения
# - Нажмите "Create pull request"

# 6. После одобрения PR, слейте через интерфейс GitHub
# 7. Удалите локальную ветку
git checkout main
git pull origin main
git branch -d feature/add-contact-form
```

### Полезные Git команды

```bash
# Отменить последний commit (но сохранить изменения)
git reset --soft HEAD~1

# Посмотреть историю commits
git log --oneline --graph --all

# Посмотреть изменения в файлах
git diff

# Отменить изменения в файле (до commit)
git checkout -- src/components/MyComponent.tsx

# Создать stash (временно сохранить изменения)
git stash
git stash pop  # вернуть изменения

# Посмотреть удалённые репозитории
git remote -v

# Клонировать конкретную ветку
git clone -b branch-name https://github.com/lptt/website.git
```

## 🐛 Решение проблем

### Проблема: "command not found: node"

**Решение:**

```bash
# Проверьте установлен ли Node.js
node --version

# Если нет, переустановите Node.js
# Или добавьте в PATH:

# macOS/Linux (добавьте в ~/.bashrc или ~/.zshrc):
export PATH="/usr/local/bin:$PATH"

# Windows:
# Системные переменные → Path → Добавить → C:\Program Files\nodejs\
```

### Проблема: "npm ERR! EACCES: permission denied"

**Решение (macOS/Linux):**

```bash
# НЕ используйте sudo npm install!
# Вместо этого исправьте права:

sudo chown -R $(whoami) ~/.npm
sudo chown -R $(whoami) /usr/local/lib/node_modules
```

### Проблема: "Port 3000 is already in use"

**Решение:**

```bash
# Найти процесс на порту 3000
# Windows:
netstat -ano | findstr :3000
taskkill /PID <PID> /F

# macOS/Linux:
lsof -i :3000
kill -9 <PID>

# Или используйте встроенную команду:
npm run kill:ports
```

### Проблема: "Module not found" после git pull

**Решение:**

```bash
# Переустановите зависимости
npm install
cd backend && npm install && cd ..

# Очистите кеш
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### Проблема: PostgreSQL connection error

**Решение:**

```bash
# Проверьте запущен ли PostgreSQL
# Windows:
services.msc  # Найдите postgresql-x64-14

# macOS:
brew services list

# Linux:
sudo systemctl status postgresql

# Запустите PostgreSQL если остановлен
# macOS:
brew services start postgresql@14

# Linux:
sudo systemctl start postgresql

# Проверьте DATABASE_URL в backend/.env
# Формат: postgresql://username:password@localhost:5432/database_name
```

### Проблема: "Prisma schema has drift"

**Решение:**

```bash
cd backend

# Сбросить БД (ВНИМАНИЕ: удалит все данные!)
npx prisma migrate reset

# Или создать новую миграцию
npx prisma migrate dev --name fix-schema
```

### Проблема: Frontend не подключается к Backend

**Решение:**

```bash
# 1. Проверьте работает ли backend
curl http://localhost:3000/api/public/stats

# 2. Проверьте VITE_API_URL в .env (корень проекта)
# Должно быть: VITE_API_URL=http://localhost:3000/api

# 3. Проверьте CORS в backend
# В backend/src/server.ts должно быть:
# app.use(cors({ origin: 'http://localhost:5173' }))

# 4. Перезапустите оба сервера
```

### Проблема: Медленная работа на Windows

**Решение:**

```bash
# Отключите антивирус для папки проекта
# Добавьте исключение в Windows Defender:
# Settings → Update & Security → Windows Security → 
# Virus & threat protection → Manage settings → 
# Exclusions → Add folder → Выберите папку проекта

# Используйте WSL2 для лучшей производительности
wsl --install
```

### Проблема: "Cannot find module 'framer-motion'"

**Решение:**

```bash
# Переустановите зависимости
rm -rf node_modules package-lock.json
npm install

# Если не помогло, установите вручную
npm install framer-motion
```
