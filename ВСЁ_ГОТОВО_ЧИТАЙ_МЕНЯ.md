## 🚀 БЫСТРЫЙ СТАРТ (5 МИНУТ)

### 1. Забери изменения:

```bash
cd ~/Documents/GitHub/lotto-web
rm -rf backend/node_modules backend/package-lock.json
git pull origin cursor/debug-electronic-diary-missing-sections-6f45
```

### 2. Установи зависимости:

```bash
npm install
cd backend && npm install && cd ..
```

### 3. Настрой базу:

```bash
# Запусти PostgreSQL
brew services start postgresql@14

# Создай базу
createdb lptt_db

# Настрой .env
cd backend
cat > .env << 'EOF'
DATABASE_URL="postgresql://vasiliidyahenko@localhost:5432/lptt_db"
JWT_SECRET="lptt-secret-key-2024"
JWT_EXPIRES_IN="7d"
PORT=3000
CORS_ORIGIN="http://localhost:5173"
EOF

# Примени схему
npx prisma db push

# Заполни РАСШИРЕННЫМИ данными (100+ студентов)
npm run seed:full
```

### 4. Запусти:

```bash
# Терминал 1 - Backend
cd backend
npm run dev

# Терминал 2 - Frontend
npm run dev
```

### 5. Открой браузер:

```
http://localhost:5173
```
