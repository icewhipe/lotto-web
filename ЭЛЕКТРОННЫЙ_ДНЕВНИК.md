## Функциональность

### 📊 Электронный дневник

#### Для студентов:
- **Оценки по предметам** - просмотр всех оценок с детализацией по типам (экзамен, контрольная, домашняя работа)
- **Средний балл** - автоматический расчет среднего балла по каждому предмету и общего
- **История оценок** - хронология всех полученных оценок

#### Система оценок:
- 🟢 **5** - Отлично
- 🔵 **4** - Хорошо
- 🟡 **3** - Удовлетворительно
- 🔴 **2** - Неудовлетворительно

### 📅 Расписание

- **Недельное расписание** - расписание на всю неделю с возможностью выбора дня
- **Детали занятий:**
  - Время проведения
  - Преподаватель
  - Аудитория
  - Тип занятия (лекция/практика/лабораторная)

### 📈 Посещаемость

- **Статус посещения:**
  - ✅ Присутствовал
  - ❌ Отсутствовал (с указанием причины)
  - ⏰ Опоздание

- **Статистика:**
  - Процент посещаемости
  - Количество пропусков
  - Количество опозданий
  - История посещений

## Технические улучшения

### 🚀 Оптимизация производительности

1. **Lazy Loading** - компоненты загружаются по мере необходимости
2. **Code Splitting** - разделение кода на отдельные чанки:
   - `react-vendor` - React и React Router
   - `animation-vendor` - Framer Motion
   - `icons-vendor` - Lucide Icons
   - Отдельные чанки для каждого компонента

3. **Оптимизация анимаций** - использование CSS анимаций вместо JS где возможно
4. **Terser минификация** - удаление console.log и оптимизация кода

### 🎨 UI/UX улучшения

1. **Улучшенная типографика:**
   - Inter Variable Font с оптимальными настройками
   - Правильные межстрочные интервалы
   - Отрицательные letter-spacing для больших заголовков

2. **Интегрированная навигация:**
   - Поиск и переключатель темы встроены в Navbar
   - Кнопка входа в систему на главной странице
   - Улучшенная мобильная навигация

3. **Современный дизайн:**
   - Glass morphism эффекты
   - Градиенты и плавные переходы
   - Темная тема
   - Адаптивная верстка
