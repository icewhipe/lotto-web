# 🔧 Очистка сессии в браузере

## ❌ ПРОБЛЕМА:

При открытии сайта сразу показывается админ панель.

**Причина:** В `localStorage` браузера сохранена сессия пользователя (скорее всего администратора).

---

## ✅ РЕШЕНИЕ 1: Через консоль браузера (БЫСТРО)

### Шаг 1: Открой сайт
```
http://localhost:5173
```

### Шаг 2: Открой консоль разработчика
- **macOS:** `⌘ + Option + J`
- **Windows/Linux:** `Ctrl + Shift + J`
- Или: **Правый клик → Inspect → вкладка Console**

### Шаг 3: Выполни команду
```javascript
localStorage.clear()
```

### Шаг 4: Перезагрузи страницу
- **macOS:** `⌘ + R`
- **Windows/Linux:** `Ctrl + R`

**Готово!** Теперь увидишь главную страницу сайта.

---

## ✅ РЕШЕНИЕ 2: Через Application (детально)

### Шаг 1: Открой сайт
```
http://localhost:5173
```

### Шаг 2: Открой DevTools
- **macOS:** `⌘ + Option + I`
- **Windows/Linux:** `F12`

### Шаг 3: Перейди на вкладку Application
- Вверху: **Elements | Console | Sources | Network | → Application**

### Шаг 4: Найди Local Storage
- Слева: **Storage → Local Storage → http://localhost:5173**

### Шаг 5: Удали ключ lptt_user
- Найди строку: `lptt_user`
- Правый клик → **Delete**

**ИЛИ**

- Правый клик на `http://localhost:5173` → **Clear**

### Шаг 6: Перезагрузи страницу
- **⌘ + R** (macOS) или **Ctrl + R** (Windows)

---

## ✅ РЕШЕНИЕ 3: Кнопка выхода (если видишь интерфейс)

Если попал в админ панель:

1. Найди кнопку **"Выход"** или **"Logout"** (обычно справа вверху)
2. Нажми на неё
3. Вернёшься на главную страницу

---

## 🔍 КАК ЭТО ПРОИЗОШЛО?

В коде сайта есть проверка при загрузке:

```tsx
useEffect(() => {
  // Check for saved user session
  const savedUser = localStorage.getItem('lptt_user')
  if (savedUser) {
    setUser(JSON.parse(savedUser))
  }
}, [])
```

Если в `localStorage` есть `lptt_user` → автоматически авторизует.

**Ты ранее логинился как админ** → сессия сохранилась → сайт сразу показывает админ панель.

## 🛠️ ПОЛЕЗНЫЕ КОМАНДЫ В КОНСОЛИ

```javascript
// Посмотреть что сохранено
localStorage.getItem('lptt_user')

// Очистить всё
localStorage.clear()

// Удалить конкретный ключ
localStorage.removeItem('lptt_user')

// Посмотреть все ключи
Object.keys(localStorage)
```
