# 🚀 ПРАВИЛЬНЫЙ ЗАПУСК Backend

## ❌ НЕПРАВИЛЬНО:

```bash
cd backend
npm start  # ❌ Это для production, требует компиляции
```

**Ошибка:** `Cannot find module '/Users/.../backend/dist/server.js'`

**Причина:** `npm start` ищет скомпилированный файл `dist/server.js`, но его нет (нужна компиляция TypeScript).

---

## ✅ ПРАВИЛЬНО:

### Вариант 1: Запустить ВСЁ из корня (РЕКОМЕНДУЕТСЯ)

```bash
# Вернись в корень проекта
cd /Users/vasiliidyahenko/Documents/GitHub/lotto-web

# Запусти Backend + Frontend одновременно
npm start
```

**Это запустит:**
- 🔧 Backend (development mode, с tsx watch)
- 🎨 Frontend (vite)

---

### Вариант 2: Только Backend (development)

```bash
cd /Users/vasiliidyahenko/Documents/GitHub/lotto-web/backend

npm run dev
```

**Это использует `tsx watch` — не требует компиляции!**

---

### Вариант 3: Backend для Production

Если нужен production build:

```bash

# Теперь можно запустить

```

## 🎯 КОМАНДЫ В BACKEND:

```bash
cd backend

# Development (БЕЗ компиляции, hot reload)
npm run dev        # ✅ Используй это для разработки!

# Production (С компиляцией)
npm run build      # Компилировать TypeScript → dist/
npm start          # Запустить скомпилированный код

# Database
npx prisma generate     # Генерировать Prisma Client
npx prisma migrate dev  # Применить миграции
npx prisma studio       # Открыть GUI для БД

# Seed (заполнить тестовыми данными)
npm run seed
```

## 🔍 РАЗНИЦА МЕЖДУ КОМАНДАМИ:

| Команда | Где запускать | Что делает | Когда использовать |
|---------|---------------|------------|-------------------|
| `npm start` | **Корень проекта** | Запускает Backend + Frontend | ✅ Всегда для разработки |
| `npm run dev:all` | **Корень проекта** | Быстрый запуск всего | ✅ Альтернатива npm start |
| `npm run dev` | `backend/` | Только Backend (dev) | Когда frontend не нужен |
| `npm start` | `backend/` | Backend (production) | ❌ Требует npm run build |
| `npm run build` | `backend/` | Компилирует TypeScript | Только для production |
