# 🔧 Исправление Git конфликта

## ❌ Ошибка:
```
error: Pulling is not possible because you have unmerged files.
```

---

## ✅ БЫСТРОЕ РЕШЕНИЕ (рекомендуется):

### Вариант 1: Сбросить изменения и взять с Git

```bash
cd /Users/vasiliidyahenko/Documents/GitHub/lotto-web/backend

# 1. Отменить все локальные изменения
git reset --hard

# 2. Забрать последнюю версию с Git
git pull origin feature/electronic-diary-optimization

# 3. Готово! Файлы обновлены
```

**Это самый простой способ!** Все изменения будут из Git.

---

## ✅ АЛЬТЕРНАТИВА: Решить конфликт вручную

### Шаг 1: Посмотреть конфликтные файлы

```bash
git status
```

Ищи строки с `both modified:` или `Unmerged paths:`

---

### Шаг 2: Открыть конфликтный файл

```bash
# Например, если конфликт в .env
open -a TextEdit .env
```

Найди строки с маркерами:
```
<<<<<<< HEAD
ваши изменения
=======
изменения из Git
>>>>>>> branch
```

---

### Шаг 3: Выбрать нужную версию

Удали маркеры и оставь нужный код:

```bash
# Было:
<<<<<<< HEAD
DATABASE_URL="postgresql://postgres@localhost:5432/lptt_db"
=======
DATABASE_URL="postgresql://vasiliidyahenko@localhost:5432/lptt_db"
>>>>>>> feature/electronic-diary-optimization

# Стало (оставь версию из Git):
DATABASE_URL="postgresql://vasiliidyahenko@localhost:5432/lptt_db"
```

---

### Шаг 4: Сохранить и добавить в Git

```bash
# Сохрани файл (⌘ + S в редакторе)

# Добавь в Git
git add .env

# Сделай commit
git commit -m "fix: resolved merge conflict"

# Теперь можно pull
git pull origin feature/electronic-diary-optimization
```
