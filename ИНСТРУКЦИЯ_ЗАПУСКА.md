## 🚀 КАК ЗАПУСТИТЬ НА МАКБУКЕ:

### Шаг 1: Забери все изменения

```bash
cd ~/Documents/GitHub/lotto-web

```

### Шаг 2: Проверь PostgreSQL

```bash
# Проверь что PostgreSQL запущен
brew services list | grep postgresql

# Если не запущен - запусти
brew services start postgresql@14

# Проверь что база lptt_db существует
psql -l | grep lptt_db

# Если нет - создай
createdb lptt_db
```

### Шаг 3: Backend Setup (если ещё не делал)

```bash
cd ~/Documents/GitHub/lotto-web/backend

# Установи зависимости (если ещё не делал)
npm install

# Проверь .env файл
cat .env

# Должно быть:
# DATABASE_URL="postgresql://vasiliidyahenko@localhost:5432/lptt_db"
# JWT_SECRET="lptt-secret-key-2024"
# PORT=3000
# CORS_ORIGIN="http://localhost:5173"

# Примени схему Prisma (если ещё не делал)
npx prisma db push

# Заполни БД данными (если ещё не делал)
npm run seed:full
```

#### C. Управление специальностями:
1. Нажми "Специальности" в меню
2. Увидишь 3 специальности

4. Заполни код, название, срок обучения, описание
5. Создай новую

#### D. Управление расписанием:
1. Нажми "Расписание" в меню
2. Выбери группу из dropdown
3. Выбери день недели
4. Нажми "Добавить пару"
5. Заполни предмет, кабинет, тип занятия

#### E. Инвайт-коды:
1. Нажми "Инвайт-коды" в меню
2. Увидишь демо коды
3. Нажми "Сгенерировать коды"
4. Выбери группу, количество, срок
