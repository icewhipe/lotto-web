# 🐛 БАГ ИСПРАВЛЕН: Белый экран при загрузке

## ❌ Проблема

Вы столкнулись с **белым экраном** при загрузке сайта.

### Причина
В `src/App.tsx` был fallback код, который использовал несуществующие компоненты:
- `PageLoader` - не импортирован
- `UnderConstruction` - не импортирован

Когда React пытался отрендерить fallback, он крашился из-за отсутствия этих компонентов → **белый экран**.

---

## ✅ Что исправлено

### 1. Удалён сломанный fallback
```diff
- // Старый код (крашился)
- return (
-   <AnimatePresence mode="wait">
-     <motion.div>
-       <PageLoader />  ❌ не существует
-       <UnderConstruction />  ❌ не существует
-     </motion.div>
-   </AnimatePresence>
- )

+ // Новый код (работает)
+ return (
+   <FullSite 
+     onNavigateToDiary={() => setShowLogin(true)}
+     isDarkMode={isDarkMode}
+     onToggleTheme={toggleTheme}
+   />
+ )
```

### 2. Transition показывается только 1 раз
Теперь liquid glass анимация показывается **только при первом посещении** в рамках сессии браузера:

```typescript
// Проверка через sessionStorage
const hasSeenTransition = sessionStorage.getItem('hasSeenTransition') === 'true'

const [showTransition, setShowTransition] = useState(!hasSeenTransition)
const [showFullSite, setShowFullSite] = useState(hasSeenTransition)
```

**Результат:**
- 1-й визит: заглушка (2.6s) → сайт
- 2-й визит (обновление): сразу сайт ⚡
- Новая вкладка: заглушка снова

### 3. Исправлены TypeScript ошибки
- Удалена неиспользуемая переменная `opacity`
- Убран дублирующийся `style` атрибут
