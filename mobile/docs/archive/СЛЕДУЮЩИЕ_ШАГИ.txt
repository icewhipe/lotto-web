📱 iOS ПРИЛОЖЕНИЕ (СЕЙЧАС):

1. Открыть инструкцию:
   ios-native/БЫСТРЫЙ_СТАРТ.md

2. Создать Xcode проект (5 минут):
   - Xcode → File → New → Project
   - iOS → App → SwiftUI
   - Name: LPTTDiary
   - Перетащить все папки из LPTTDiary/
   - ⌘R - готово!

3. Войти:
   student@lptt.ru / 123456

═══════════════════════════════════════════════════════════

🗄️ BACKEND API (1-2 НЕДЕЛИ):

1. Setup PostgreSQL:
   createdb lptt_diary

2. Configure:
   cd backend
   cp .env.example .env
   # Edit DATABASE_URL, JWT_SECRET

3. Migrate:
   npx prisma migrate dev

4. Implement API:
   - /auth/* endpoints
   - /students/* endpoints
   - /grades/* endpoints
   - etc.

5. Deploy:
   railway up

═══════════════════════════════════════════════════════════

🔗 ИНТЕГРАЦИЯ (1 НЕДЕЛЯ):

1. Подключить Web к Backend:
   src/services/api.ts → API_URL

2. Подключить iOS к Backend:
   Services/APIService.swift → baseURL

3. Тестирование:
   - Auth flow
   - Data sync
   - Real-time (Socket.IO)
