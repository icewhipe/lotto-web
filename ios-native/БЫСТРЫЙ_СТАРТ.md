## 🚀 За 2 минуты в 4 шага!

---

## Шаг 1: Открыть Xcode
```bash
# Просто запустить Xcode
open -a Xcode
```

---

## Шаг 2: Создать проект

**File → New → Project...**

Выбрать:
- **iOS → App**
- **Next**

Настроить:
- **Product Name:** `LPTTDiary`
- **Organization Identifier:** `ru.lptt`
- **Interface:** `SwiftUI` ✅
- **Language:** `Swift` ✅
- **Next**

Сохранить в:
```
/Users/vasiliidyahenko/Documents/GitHub/lotto-web/ios-native/
```

---

## Шаг 3: Добавить файлы

### Вариант A: Drag & Drop (проще!)

1. Открыть в Finder:
   ```
   ios-native/LPTTDiary/
   ```

2. Перетащить **ВСЕ ПАПКИ** в Xcode:
   ```
   App/
   Views/
   Models/
   ViewModels/
   Services/
   Components/
   Utils/
   ```

3. В диалоге выбрать:
   - ✅ Copy items if needed
   - ✅ Create groups
   - ✅ Add to targets: LPTTDiary

### Вариант B: Через Xcode

**File → Add Files to "LPTTDiary"...**
- Выбрать папку `ios-native/LPTTDiary/`
- Отметить все
- Options: ✅ Copy items, ✅ Create groups
- **Add**

---

## Шаг 4: Запустить!

1. Выбрать **iPhone 15 Pro** симулятор
2. Нажать **⌘R**
3. Войти:
   ```
   student@lptt.ru / 123456
   ```

---

## 🎉 ГОТОВО!

**Приложение запущено!** 🍎

---

## 🔧 Если есть ошибки:

**1. Duplicate files:**
- Удалить дефолтные `ContentView.swift` и `LPTTDiaryApp.swift`

**2. Target membership:**
- Выбрать файл → Inspector → Target Membership → ✅ LPTTDiary

**3. Bundle ID:**
- Target → General → Bundle Identifier: `ru.lptt.diary`
