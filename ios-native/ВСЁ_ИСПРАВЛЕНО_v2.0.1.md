## 📊 ДЕТАЛИ ИСПРАВЛЕНИЙ:

### **Parsing времени:**
```swift
// Входные форматы:
"09:00"           → start: "09:00", end: nil
"09:00-10:45"     → start: "09:00", end: "10:45"
"09:00 - 10:45"   → start: "09:00", end: "10:45" (с trim)

// Код:
let parts = time.components(separatedBy: "-")
let start = parts.first?.trimmingCharacters(in: .whitespaces)
let end = parts.count > 1 ? parts[1].trimmingCharacters(in: .whitespaces) : nil
```

### **LessonType mapping:**
```swift
// Type → Badge
.lecture   → "ЛК"  (Лекция)
.practice  → "ПР"  (Практика)
.lab       → "ЛБ"  (Лабораторная)
.seminar   → "СМ"  (Семинар)

// Type → Color
.lecture   → Blue   (#3b82f6)
.practice  → Green  (#10b981)

.seminar   → Orange (#f59e0b)
```

// Модель:
