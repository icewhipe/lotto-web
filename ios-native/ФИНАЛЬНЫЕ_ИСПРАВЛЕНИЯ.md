## 📋 МОДЕЛЬ NOTE:

```swift
struct Note {
    let id: String
    let title: String
    let description: String    // ✅ НЕ content!
    let subject: String
    let author: String
    let authorId: String
    let date: Date
    let rating: Double
    let downloads: Int
    let size: String           // ✅ НЕ pages!
    let fileUrl: String        // ✅ String, НЕ String?
}
```
