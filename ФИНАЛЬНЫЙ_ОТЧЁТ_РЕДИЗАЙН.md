## 🚀 КАК ЗАПУСТИТЬ

### Quick Start:

```bash
# 1. Клонировать репозиторий
git clone https://github.com/lptt/website.git
cd website

# 2. Установить зависимости
npm install
cd backend && npm install && cd ..

# 3. Настроить .env файлы
# backend/.env - DATABASE_URL, JWT_SECRET
# .env - VITE_API_URL

# 4. Инициализировать БД
cd backend
npx prisma migrate dev --name init
npx prisma generate
npm run seed
cd ..

# 5. Запустить проект
npm run dev:all

# 6. Открыть в браузере
# http://localhost:5173
```

**Подробная инструкция:** См. `НАЧАЛО_РАБОТЫ.md`

## ⚠️ ВАЖНЫЕ ЗАМЕТКИ

### Для Frontend команды:

1. **Не забудьте:** Проверить все изображения должны быть оптимизированы (AVIF/WebP)
2. **Важно:** Lazy loading работает только при scroll - тестируйте с прокруткой
3. **Accessibility:** Тестируйте с keyboard navigation (Tab, Enter, Esc)
4. **Performance:** Bundle analyzer покажет большие chunks: `npm run build && npm run analyze`

### Для Backend команды:

1. **API:** Реализуйте endpoints из `backend/docs/API_PUBLIC_ENDPOINTS.md`
2. **CORS:** Настройте правильные origins (localhost:5173 для dev)
3. **Rate Limiting:** Добавьте для публичных endpoints (особенно POST)
4. **Caching:** Используйте Redis для frequently accessed data

### Для DevOps команды:

1. **Environment:** 3 окружения - development, staging, production
2. **CDN:** Настройте для статических ресурсов (images, fonts)
3. **SSL:** Обязательно HTTPS на production
4. **Monitoring:** Настройте uptime monitoring и alerts
5. **Backup:** Ежедневный backup БД
