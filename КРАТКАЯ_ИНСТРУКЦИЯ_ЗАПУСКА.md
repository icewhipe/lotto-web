## 📥 ШАГ 1: Установка программ

### 1.1. Node.js (обязательно)

**Что это?** Платформа для запуска JavaScript приложений.

**Как установить:**

1. Откройте [nodejs.org](https://nodejs.org/)
2. Нажмите зелёную кнопку **"Download Node.js (LTS)"**
3. Запустите скачанный файл
4. Нажимайте "Далее" → "Далее" → "Установить"
5. Перезагрузите компьютер

**Проверка:**
```bash
# Откройте терминал (Windows: Win+R → cmd)
node --version
# Должно показать: v18.x.x или выше
```

### 1.2. Git (обязательно)

**Что это?** Система контроля версий для работы с кодом.

**Как установить:**

1. Откройте [git-scm.com](https://git-scm.com/)
2. Нажмите **"Download for Windows"** (или для вашей ОС)
3. Запустите установщик
4. Используйте настройки по умолчанию (просто нажимайте "Далее")

**Проверка:**
```bash
git --version
# Должно показать: git version 2.x.x
```

### 1.3. PostgreSQL (для backend)

**Что это?** База данных.

**Как установить:**

1. Откройте [postgresql.org/download](https://www.postgresql.org/download/)
2. Выберите вашу ОС
3. Скачайте и запустите установщик
4. **ВАЖНО:** Запомните пароль, который вводите для пользователя `postgres`

## ⚙️ ШАГ 3: Настройка проекта

### 3.1. Установка зависимостей

```bash
# Убедитесь, что вы в папке проекта (должен быть файл package.json)

# Установить зависимости frontend (займёт 5-7 минут)
npm install

# Установить зависимости backend
cd backend
npm install
cd ..
```

**☕ Идите попить чай, пока устанавливается (~10 минут)**

### 3.2. Создание базы данных

```bash
# Откройте PostgreSQL командную строку
# Windows: Пуск → PostgreSQL → SQL Shell (psql)
# Введите пароль, который создавали при установке

# В консоли PostgreSQL выполните:
CREATE DATABASE lptt_db;
\q
```

### 3.3. Создание файлов настроек

#### Файл 1: `backend/.env`

```bash
# Создайте файл backend/.env с таким содержимым:

DATABASE_URL="postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/lptt_db"
JWT_SECRET="super_secret_key_12345"
PORT=3000
NODE_ENV=development
FRONTEND_URL="http://localhost:5173"
```

**⚠️ ВАЖНО:** Замените `ВАШ_ПАРОЛЬ` на пароль от PostgreSQL!

#### Файл 2: `.env` (в корне)

```bash
# Создайте файл .env в корне проекта:

VITE_API_URL=http://localhost:3000/api
```

**💡 Совет:** Используйте Блокнот (Windows) или TextEdit (Mac) для создания файлов.

### 3.4. Инициализация базы данных

```bash
# Перейдите в папку backend
cd backend

# Создайте таблицы в БД
npx prisma migrate dev --name init

# Заполните тестовыми данными (опционально)
npm run seed

# Вернитесь в корень
cd ..
```

## 🐛 Что делать если не работает?

### Проблема 1: "command not found: npm"

**Решение:** Node.js не установлен или не добавлен в PATH
```bash
# Переустановите Node.js с официального сайта
# После установки перезагрузите компьютер
```

### Проблема 2: "Port 3000 is already in use"

**Решение:** Порт занят другим процессом
```bash
# Windows:
netstat -ano | findstr :3000
taskkill /PID <номер> /F

# Mac/Linux:
lsof -i :3000
kill -9 <номер>
```

### Проблема 3: "Database connection error"

**Решение:** PostgreSQL не запущен или неверный пароль
```bash
# Проверьте запущен ли PostgreSQL:
# Windows: services.msc → найдите postgresql-x64-14
# Mac: brew services list

# Проверьте пароль в backend/.env
```

### Проблема 4: "Module not found"

**Решение:** Зависимости не установлены
```bash
# Переустановите зависимости:
rm -rf node_modules package-lock.json
npm install

cd backend
rm -rf node_modules package-lock.json
npm install
cd ..
```
