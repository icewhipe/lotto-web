### 2. Безопасность (XSS, CSRF)

**Критические уязвимости:**

#### A. XSS (Cross-Site Scripting)
- ❌ **Опасность:** Пользовательский input не санитизируется
- **Файлы:** `NewsManager`, `GalleryManager`, формы
- **Решение:** Добавить DOMPurify или sanitize-html

#### B. CSRF (Cross-Site Request Forgery)
- ❌ **Опасность:** Нет CSRF токенов
- **Файлы:** Backend API
- **Решение:** Добавить CSRF middleware

#### C. SQL Injection
- ✅ **Защищено:** Prisma ORM (параметризованные запросы)

#### D. Аутентификация
- ⚠️ **Слабая:** Mock данные, пароль 123456
- **Решение:** JWT токены, bcrypt хэширование
