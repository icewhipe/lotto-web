npm run dev:all

## ⚠️ Если возникнут проблемы

### Проблема 1: Конфликт при pull
```bash
git reset --hard origin/liquid-glass-redesign-2025
npm install
npm run dev:all
```

### Проблема 2: Ошибка установки
```bash
rm -rf node_modules backend/node_modules
npm install
cd backend && npm install && cd ..
npm run dev:all
```

### Проблема 3: База данных
```bash
cd backend
npx prisma generate
npx prisma db push
cd ..
npm run dev:all
```
