## 🏁 БЫСТРЫЙ СТАРТ

### Вариант 1: Запустить ВСЁ (Backend + Web + iOS)

#### 📝 Шаг 1: Clone repository
```bash
git clone https://github.com/icewhipe/lotto-web.git
cd lotto-web
git checkout feature/electronic-diary-optimization
```

#### 🗄️ Шаг 2: Запустить Backend

```bash
# Перейти в папку backend
cd backend

# Установить зависимости
npm install

# Создать БД PostgreSQL
createdb lptt_dev

# Создать .env файл
cat > .env << EOF
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/lptt_dev"
JWT_SECRET="super-secret-jwt-key-change-in-production"
JWT_EXPIRES_IN="7d"
PORT=5000
FRONTEND_URL="http://localhost:5173"
NODE_ENV="development"
EOF

# Prisma setup
npm run prisma:generate
npm run prisma:migrate

# Заполнить тестовыми данными
npm run seed

# 🚀 ЗАПУСК!
npm run dev
```

**Результат:**
```
🚀 Server running on http://localhost:5000
📡 Socket.IO ready
🌍 Environment: development
```

✅ **Backend работает!**

## 🔧 Решение проблем

### PostgreSQL не запускается

**macOS:**
```bash
brew services start postgresql
```

**Windows:**
```bash
# Start PostgreSQL service
net start postgresql-x64-14
```

**Docker:**
```bash
docker run --name lptt-postgres \
  -e POSTGRES_DB=lptt_dev \
  -e POSTGRES_PASSWORD=postgres \
  -p 5432:5432 \
  -d postgres
```

---

### Backend не стартует

**Проверить:**
```bash
# PostgreSQL работает?
psql -U postgres -d lptt_dev

# .env файл существует?
cat .env

# Prisma миграции выполнены?
npm run prisma:migrate

# Зависимости установлены?
npm install
```

---

### Web не подключается к Backend

**Проверить:**
1. Backend запущен? → http://localhost:5000/api/health
2. CORS настроен? → Проверить `FRONTEND_URL` в .env
3. Network tab в DevTools → Смотреть ошибки

**Исправить:**
```typescript
// src/services/api.ts
const API_URL = 'http://localhost:5000/api'; // ✅
```

---

### iOS не подключается к Backend

**Проблема:** localhost не работает на симуляторе

**Решение:**
1. Найти IP компьютера:
   ```bash
   ifconfig | grep "inet "
   # Пример: inet 192.168.1.5
   ```

2. Обновить `mobile/src/services/api.ts`:
   ```typescript
   const API_BASE_URL = 'http://192.168.1.5:5000/api';
   ```

3. Перезапустить iOS:
   ```bash
   npm run ios
   ```

---

### Prisma ошибки

**"Can't reach database server":**
```bash
# Проверить PostgreSQL
psql -U postgres

# Проверить DATABASE_URL в .env
cat .env | grep DATABASE_URL
```

**"Migration failed":**
```bash
# Сбросить БД
npm run prisma:migrate reset

# Заново мигрировать
npm run prisma:migrate

# Заполнить данными
npm run seed
```

---

### Port уже занят

**Если 5000 или 5173 заняты:**

**Backend:**
```bash
# Изменить PORT в .env
PORT=5001

# Перезапустить
npm run dev
```

**Web:**
```bash
# Vite автоматически выберет другой порт
# Или указать явно:
npm run dev -- --port 5174
```
